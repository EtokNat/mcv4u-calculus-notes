Where this lesson sits

So far we have treated \(\dfrac{d}{dx}\sin x = \cos x\) as a given.

Today we establish that fact, extend it to \(\cos\), \(\tan\), and the family \(\sin,\cos,\tan,\cot,\sec,\csc\).

Then we do the same for the exponential family: \(e^{x}\) and \(a^{x}\).

Finally we combine them with the chain rule — things like \(e^{\sin x}\) and \(\sin(3x^{2}+1)\).

Part 1 — Trigonometric Derivatives

Why these rules?

Graph \(y=\sin x\) and read off its slope at many points.

The slope-vs-\(x\) plot you get is identical to \(y = \cos x\).

Do the same for \(y=\cos x\). The slope plot is \(-\sin x\).

(The formal proof uses \(\lim_{h\to 0}\dfrac{\sin h}{h}=1\). Ontario does not require it.)

The two core rules

\[\dfrac{d}{dx}\sin x = \cos x\]

\[\dfrac{d}{dx}\cos x = -\sin x\]

Memory hook: \(\cos\) has a minus sign — same letter count as "minus".

The other four follow from these

From the quotient/reciprocal structure:

\[\dfrac{d}{dx}\tan x = \sec^{2}x\]

\[\dfrac{d}{dx}\cot x = -\csc^{2}x\]

\[\dfrac{d}{dx}\sec x = \sec x\,\tan x\]

\[\dfrac{d}{dx}\csc x = -\csc x\,\cot x\]

We derived \(\tan\) in the Product & Quotient lesson. The others come out the same way.

Example 1 — \(y = \sin(3x)\)

Differentiate.

Step 1. It's a composite: outside = \(\sin\), inside = \(3x\).

Step 2. Chain rule template: \(\dfrac{d}{dx}f(g(x)) = f'(g(x))\cdot g'(x).\)

Step 3. \(f'(\sin) = \cos\), so \(f'(g(x)) = \cos(3x)\).

Step 4. \(g'(x) = 3\).

Step 5. Multiply: \(y' = \cos(3x)\cdot 3\).

\(y' = 3\cos(3x).\)

Example 2 — \(y = \cos(2x+1)\)

Step 1. Outside = \(\cos\), inside = \(2x+1\).

Step 2. Derivative of outside (keeping inside): \(-\sin(2x+1)\).

Step 3. Derivative of inside: \(2\).

Step 4. Multiply: \(y' = -\sin(2x+1)\cdot 2\).

\(y' = -2\sin(2x+1).\)

Example 3 — \(y = x^{2}\sin x\)

Not a composite — it's a product.

Step 1. Let \(u = x^{2}\), \(v = \sin x\).

Step 2. \(u' = 2x\), \(v' = \cos x\).

Step 3. Product rule: \(y' = u'v + uv'\).

Step 4. \(y' = (2x)(\sin x) + (x^{2})(\cos x)\).

\(y' = 2x\sin x + x^{2}\cos x.\)

Part 2 — Exponential Derivatives

The key insight

For \(f(x) = a^{x}\) with \(a > 0\), \(a \ne 1\):

The slope at every point is proportional to the function value itself.

\[f'(x) = k\cdot f(x)\]

The constant \(k\) depends on the base \(a\).

Big question: what base makes \(k = 1\)?

Introducing \(e\)

The base for which \(f'(x) = f(x)\) exactly is called \(e\).

\(e \approx 2.71828\ldots\) — an irrational number, like \(\pi\).

\[\dfrac{d}{dx}e^{x} = e^{x}\]

The slope of \(y = e^{x}\) at any point equals the height of the curve there.

The general rule

For any positive base \(a \ne 1\):

\[\dfrac{d}{dx}a^{x} = a^{x}\ln a\]

The \(e\)-case is just the special case \(a = e\).

Because \(\ln e = 1\), we get \(\dfrac{d}{dx}e^{x} = e^{x}\cdot 1 = e^{x}.\) ✓

Example 4 — \(y = e^{x^{2}}\)

Differentiate.

Step 1. Composite: outside = \(e^{(\cdot)}\), inside = \(x^{2}\).

Step 2. Derivative of outside (keeping inside): \(e^{x^{2}}\).

Step 3. Derivative of inside: \(2x\).

Step 4. Multiply: \(y' = e^{x^{2}}\cdot 2x\).

\(y' = 2x\,e^{x^{2}}.\)

Example 5 — \(y = x\,e^{x}\)

A product.

Step 1. \(u = x\), \(v = e^{x}\).

Step 2. \(u' = 1\), \(v' = e^{x}\).

Step 3. Product rule: \(y' = u'v + uv'\).

Step 4. \(y' = (1)e^{x} + x\,e^{x}\).

Step 5. Factor out \(e^{x}\).

\(y' = (1+x)\,e^{x}.\)

Example 6 — \(y = 2^{x}\)

A straight application of \(\dfrac{d}{dx}a^{x} = a^{x}\ln a\).

Set \(a = 2\).

\(y' = 2^{x}\ln 2.\)

Numerically: \(\ln 2 \approx 0.693\), so at \(x = 0\) the slope is about \(0.693\).

Example 7 — \(y = e^{\sin x}\)

This is where Part 1 meets Part 2.

Step 1. Composite: outside = \(e^{(\cdot)}\), inside = \(\sin x\).

Step 2. Derivative of outside (keeping inside): \(e^{\sin x}\).

Step 3. Derivative of inside: \(\cos x\).

Step 4. Multiply: \(y' = e^{\sin x}\cdot \cos x\).

\(y' = \cos x\,e^{\sin x}.\)

Summary — every rule in one place

FunctionDerivative
\(\sin x\)\(\cos x\)
\(\cos x\)\(-\sin x\)
\(\tan x\)\(\sec^{2} x\)
\(\cot x\)\(-\csc^{2} x\)
\(\sec x\)\(\sec x\,\tan x\)
\(\csc x\)\(-\csc x\,\cot x\)
\(e^{x}\)\(e^{x}\)
\(a^{x}\)\(a^{x}\ln a\)

With chain rule: replace \(x\) by \(g(x)\) inside and multiply by \(g'(x)\).

Class task

Work each problem in your book. Answers reveal on click.

C1 — Differentiate \(y = \sin(x^{2})\)

\(y' = 2x\cos(x^{2}).\)

C2 — Differentiate \(y = e^{3x}\cos x\)

\(y' = e^{3x}\bigl(3\cos x - \sin x\bigr).\)

H1 — Differentiate \(y = \cos(5x+1)\)

\(y' = -5\sin(5x+1).\)

H2 — For \(y = e^{-2x}\), find \(y'(0)\)

\(y'(0) = -2.\)

H3 — Differentiate \(y = \tan(3x)\)

\(y' = 3\sec^{2}(3x).\)

H4 — Differentiate \(y = \dfrac{e^{x}}{x}\)

Write it as \(e^{x}\cdot x^{-1}\) and use the product rule.

\(y' = \dfrac{(x-1)\,e^{x}}{x^{2}}.\)

Operations with Algebraic Vectors in R² and R³

Nelson Calculus and Vectors 12 §§6.6–6.7 — componentwise addition, subtraction, and scalar multiplication.

🎯 Learning Goals

By the end of this lesson, you can:

  • Convert between component form (a, b[, c]) and the i, j, k form.
  • Add, subtract, and scale algebraic vectors component by component in R² and R³.
  • Find AB from two points (head minus tail) and compute magnitudes.

💡 Minds On

Geometry gave us the rules — add head-to-tail, scale along the line. Coordinates turn those rules into arithmetic: adding vectors becomes adding lists of numbers, and the picture is optional. Today the parallelogram law becomes a one-line calculation.

  2. The sum's head should be at (1+4, 3+(-2)) = (5,1). Plot (5,1) and draw the parallelogram — the diagonal lands exactly there.

📖 Learn — step by step

Key term — Standard unit vectors: in R², i = (1, 0) and j = (0, 1); in R³ add k = (0, 0, 1). Every vector writes uniquely as (a, b) = ai + bj or (a, b, c) = ai + bj + ck.
  • Two names, one vector. (a, b) and ai + bj are the same arrow written two ways. Convert freely: (2, −1) = 2i − j, and −3i + j − 5k = (−3, 1, −5). The i, j, k form shows the recipe; the component form shows the result.
  • Componentwise operations. (a, b) ± (c, d) = (a ± c, b ± d); m(a, b) = (ma, mb). Same in R³ with three components. This is the parallelogram law and scalar multiplication, computed.
  • Between two points: head minus tail. For A(x₁, y₁) and B(x₂, y₂): AB = OB − OA = (x₂ − x₁, y₂ − y₁). In R³: AB = (x₂ − x₁, y₂ − y₁, z₂ − z₁). The vector AB is equivalent to the position vector with those components.
  • Magnitudes. |OP| = √(a² + b²) in R² and √(a² + b² + c²) in R³ — Pythagoras, extended. Between points it's the distance formula: |AB| = √((x₂−x₁)² + (y₂−y₁)² (+ (z₂−z₁)²)).

Example 1 — Given a = (1, 3) and b = (4, −2), find the components of a + b and a − b.

Solution. Add and subtract matching components:
a + b = (1 + 4, 3 + (−2)) = (5, 1).
a − b = (1 − 4, 3 − (−2)) = (−3, 5).
Geometrically these are the two diagonals of the parallelogram on a and b.

Example 2 — A(−3, 7), B(5, −2), C(8, 18) are three points in R². (a) Find the perimeter of △ABC. (b) Find |AB + BC|.

Solution.
(a) Head minus tail: AB = (8, −9), BC = (3, 20), CA = (−11, −11).
|AB| = √(64 + 81) = √145 ≈ 12.04; |BC| = √(9 + 400) = √409 ≈ 20.22; |CA| = √(121 + 121) = √242 ≈ 15.56.
Perimeter ≈ 12.04 + 20.22 + 15.56 = 47.82.
(b) AB + BC = AC = (11, 11), so |AB + BC| = √242 ≈ 15.56 — adding consecutive sides just gives the third side.

Example 3 — For a = −i + 2j + k, b = 2j − 3k, c = i − 3j + 2k, find 2a − b + c.

Solution. Work in the i, j, k form, collecting like unit vectors:
2a − b + c = 2(−i + 2j + k) − (2j − 3k) + (i − 3j + 2k)
= −2i + 4j + 2k − 2j + 3k + i − 3j + 2k
= (−2 + 1)i + (4 − 2 − 3)j + (2 + 3 + 2)k
= −i − j + 7k = (−1, −1, 7).

Example 4 — For x = 2i − 3j and y = −4i − 3j, find |x + y| and |x − y|.

Solution. x = (2, −3), y = (−4, −3).
x + y = (−2, −6), so |x + y| = √(4 + 36) = √40 ≈ 6.32.
x − y = (6, 0), so |x − y| = 6.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercises 6.6–6.7.

Question 1 — Write OB = 3i + 4j − 4k in component form and find |OB|.

(3, 4, −4); |OB| = √(9 + 16 + 16) = √41.

Question 2 — For A(−1, 3) and B(2, 5), find AB in component form and |AB|.

AB = (2 − (−1), 5 − 3) = (3, 2); |AB| = √(9 + 4) = √13.

Question 3 — If ai + 5j = (−3, b), find a and b.

Match components: a = −3, b = 5.

Question 4 — For m = 2i − k and n = −2i + j + 2k, find |m − n|.

m − n = (2 − (−2), 0 − 1, −1 − 2) = (4, −1, −3); |m − n| = √(16 + 1 + 9) = √26.

📝 Lesson Summary

Key ideas

  • (a, b) = ai + bj; (a, b, c) = ai + bj + ck — convert freely.
  • Add/subtract matching components; scale every component.
  • AB = head − tail; magnitudes via Pythagoras / the distance formula.

Need to know

  • Scalar multiplication hits all components: 3(1, −2, 5) = (3, −6, 15) — never just one.

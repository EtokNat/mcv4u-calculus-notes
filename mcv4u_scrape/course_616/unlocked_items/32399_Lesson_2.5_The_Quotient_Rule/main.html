The Quotient Rule

🎯 Learning Goals

  • Choose between the quotient rule and the product + power-of-a-function route.

💡 Minds On

Just as the derivative of a product is not the product of the derivatives, the derivative of a quotient is not the quotient of the derivatives. The quotient rule gives the derivative of a quotient of two functions — and it is derived from the product rule.

🔍 Explore — two routes, one answer

  1. In Desmos, graph y = (3x - 4)/(x^2 + 5) (Example 1 below).
  2. Graph its derivative y = (-3x^2 + 8x + 15)/(x^2 + 5)^2. Check the slope at x = 0 with a tangent line.
  3. The same function can be written (3x − 4)(x² + 5)⁻¹ and differentiated with the product rule — verify you get an equivalent result.

📖 Learn — step by step

The Quotient Rule. If h(x) = f(x)/g(x), then h′(x) = [f′(x)g(x) − f(x)g′(x)]/[g(x)]², g(x) ≠ 0. In Leibniz notation, d/dx(u/v) = [(du/dx)v − u(dv/dx)]/v².
Proof: rewrite as a product, h(x)g(x) = f(x); differentiate with the product rule, h′(x)g(x) + h(x)g′(x) = f′(x); solve for h′(x) and substitute h(x) = f(x)/g(x).
Memory aid. Both rules contain f′g and fg′. For the product rule put an addition sign between them; for the quotient rule put a subtraction sign between them, then divide by the square of the original denominator. In the quotient rule the f′g term must come first — order matters.

Example 1 — Determine the derivative of h(x) = (3x − 4)/(x² + 5).

Solution. With f(x) = 3x − 4 and g(x) = x² + 5, the quotient rule gives h′(x) = [f′(x)g(x) − f(x)g′(x)]/[g(x)]²
= [(3)(x² + 5) − (3x − 4)(2x)]/(x² + 5)²
= [3x² + 15 − 6x² + 8x]/(x² + 5)²
= (−3x² + 8x + 15)/(x² + 5)².

Example 2 — Determine the equation of the tangent to y = 2x/(x² + 1) at x = 0.

Solution. The slope at any point is dy/dx. By the quotient rule,
dy/dx = [(2)(x² + 1) − (2x)(2x)]/(x² + 1)².
At x = 0: dy/dx = [(2)(0 + 1) − (0)(0)]/(0 + 1)² = 2.
The slope at x = 0 is 2 and the point of tangency is (0, 0), so the tangent is y = 2x.

Example 3 — Determine the coordinates of each point on the graph of f(x) = (2x + 8)/√x where the tangent is horizontal.

Solution. The tangent slope at any point is f′(x). Using the quotient rule,
f′(x) = [(2)(√x) − (2x + 8)((1/2)x^(−1/2))]/(√x)²
= [2√x − (2x + 8)/(2√x)]/x
= [(2x/√x) − (x + 4)/√x]/x
= [(2x − x − 4)/√x]/x
= (x − 4)/(x√x).
The tangent is horizontal when f′(x) = 0, i.e., when x = 4. The point is (4, 8).

Two methods for rational functions. Leave the function in fraction form and use the quotient rule — e.g., f(x) = (x − 2)/(1 + x) — or express it as a product and use the product and power-of-a-function rules — e.g., f(x) = (x − 2)(1 + x)⁻¹. Both give the same derivative.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 2.4.

Question 1 — Differentiate x/(x + 1) and (2t − 3)/(t + 5) using the quotient rule.

x/(x + 1): [(1)(x + 1) − x(1)]/(x + 1)² = 1/(x + 1)². (2t − 3)/(t + 5): [(2)(t + 5) − (2t − 3)(1)]/(t + 5)² = 13/(t + 5)².

Question 2 — Find dy/dx at x = −3 for y = (3x + 2)/(x + 5).

y′ = [(3)(x + 5) − (3x + 2)(1)]/(x + 5)² = 13/(x + 5)²; at x = −3: 13/4.

Question 3 — Find the point(s) with a horizontal tangent on y = 2x²/(x − 4).

y′ = [(4x)(x − 4) − 2x²(1)]/(x − 4)² = (2x² − 16x)/(x − 4)² = 0 → x = 0 or x = 8. Points: (0, 0) and (8, 32).

Question 4 — Rewrite (x² + 3x)/x as powers and differentiate WITHOUT the quotient rule.

(x² + 3x)/x = x + 3, so the derivative is 1.

📝 Lesson Summary

Key ideas

  • The derivative of a quotient is not the quotient of the derivatives.
  • Quotient rule: (f/g)′ = [f′g − fg′]/g².

Need to know

  • Memory aid: product uses +, quotient uses − then divides by the denominator squared; the f′g term comes first.
  • Two routes for rational functions: quotient rule, or product + power-of-a-function rules.

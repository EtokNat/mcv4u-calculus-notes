Motion on a Line: Velocity and Acceleration

🎯 Learning Goals

By the end of this lesson, you can:

  • Read direction of motion and rest points from a position graph.
  • Decide when an object is speeding up or slowing down.

💡 Minds On

One reason for introducing the derivative is the need to calculate rates of change — for example, a car moving along a straight road, a ball dropped from a building, or a rocket in the early stages of flight. When studying motion along a line, we imagine the object moving on a number line, with an origin and positive/negative directions; its position relative to the origin is a function of time, s(t).

📖 Learn — step by step

Motion on a Straight Line. An object moving along a straight line with position s(t) has velocity v(t) = s′(t) and acceleration a(t) = v′(t) = s″(t) at time t. In Leibniz notation, v = ds/dt and a = dv/dt = d²s/dt². The speed of the object is |v(t)|.

Velocity is measured in m/s; acceleration in m/s². Sign conventions: v(t) > 0 means moving right, v(t) < 0 means moving left, v(t) = 0 means stationary. The object is accelerating (speeding up) when a(t) and v(t) are both positive or both negative — the product a(t)·v(t) is positive. It is decelerating (slowing down) when the signs differ — the product is negative.

Example 2 — An object moves along a straight line; its position s(t) is given by the graph shown. When is the object moving to the right, when to the left, and when is it at rest?

Solution. The object moves right whenever s(t) is increasing, or v(t) > 0. From the graph, s(t) is increasing for 0 < t < 2 and for t > 6. For 2 < t < 6, s(t) is decreasing (v(t) < 0), so the object moves left. At t = 2 the direction changes from right to left (v(t) = 0) — the object is stationary at t = 2. At t = 6 the direction changes from left to right — stationary at t = 6.

Example 3 — The position of an object moving on a line is s(t) = 6t² − t³, t ≥ 0, with s in metres and t in seconds.
a. Determine the velocity and acceleration at t = 2.   b. At what time(s) is the object at rest?   c. In which direction is it moving at t = 5?   d. When is it moving in a positive direction?   e. When does it return to its initial position?

Solution.
a. v(t) = s′(t) = 12t − 3t²; at t = 2, v(2) = 12(2) − 3(2)² = 12. a(t) = v′(t) = s″(t) = 12 − 6t; at t = 2, a(2) = 12 − 6(2) = 0. At t = 2 the velocity is 12 m/s and the acceleration is 0 m/s² — the object moves at constant velocity, neither speeding up nor slowing down.
b. At rest when v(t) = 0: 12t − 3t² = 0 → 3t(4 − t) = 0 → t = 0 or t = 4. At rest at t = 0 s and t = 4 s.
c. v(5) = 12(5) − 3(5)² = −15. Moving in a negative direction at t = 5.
d. v(t) > 0: 12t − 3t² > 0 → (divide by −3) t² − 4t < 0 → (factor) t(t − 4) < 0. A sign table (Case 1: t > 0 and t − 4 < 0; Case 2: t < 0 and t − 4 > 0) gives 0 < t < 4. The velocity graph is a parabola opening downward, confirming v(t) > 0 on 0 < t < 4 — the object moves right there.
e. s(0) = 0. Solve s(t) = 0: 6t² − t³ = 0 → (factor) t²(6 − t) = 0 → (solve) t = 0 or t = 6. Returns to its initial position after 6 s.

Example 4 — Discuss the motion of an object with position s(t) = t² − 10t, 0 ≤ t ≤ 12 (s in metres, t in seconds). Include the initial velocity, final velocity, and acceleration.

Solution. The object starts at the origin since s(0) = 0. The velocity is v(t) = s′(t) = 2t − 10 = 2(t − 5). At rest when v(t) = 0: t = 5. So the object is at rest after 5 s. v(t) > 0 for 5 < t ≤ 12 (moving right); v(t) < 0 for 0 ≤ t < 5 (moving left).
Initial velocity v(0) = −10 — moving 10 m/s to the left. Final velocity v(12) = 2(12) − 10 = 14 m/s to the right.
Acceleration a(t) = v′(t) = s″(t) = 2 m/s², constant — the velocity increases at 2 metres per second per second.
In conclusion: the object moves left for 0 ≤ t < 5 and right for 5 < t ≤ 12; initial velocity −10 m/s, final velocity 14 m/s. Extreme positions: s(5) = −25 and s(12) = 24.

Example 5 — A baseball is hit vertically upward. Its position s(t), in metres above the ground, is s(t) = −5t² + 30t + 1, with t in seconds.
a. Determine the maximum height reached by the ball.   b. Determine the velocity of the ball when it is caught 1 m above the ground.

Solution.
a. Maximum height occurs when the velocity is zero. v(t) = s′(t) = −10t + 30. Solving v(t) = 0 gives t = 3 — the moment the ball changes direction from up to down. s(3) = −5(3)² + 30(3) + 1 = 46. Maximum height: 46 m.
b. When caught, s(t) = 1: 1 = −5t² + 30t + 1 → 0 = −5t(t − 6) → t = 0 or t = 6. Since t = 0 is when the ball leaves the bat, it is caught at t = 6. v(6) = −10(6) + 30 = −30 m/s — negative, as expected for a falling ball.
Note: the graph of s(t) does not represent the ball's path — the ball moves along a vertical line, reversing direction at s = 46.

Try these on paper first, then reveal. Modelled on Exercise 3.1.

Question 1 — For s(t) = t² − 6t + 8 (t ≥ 0): (a) the velocity at time t; (b) when the velocity is zero.

(a) v(t) = 2t − 6. (b) 2t − 6 = 0 → t = 3 s.

Question 2 — An object is launched vertically at 40 m/s: s(t) = 40t − 5t². (a) When does it stop rising? (b) What is its maximum height?

(a) v(t) = 40 − 10t = 0 → t = 4 s. (b) s(4) = 160 − 80 = 80 m.

Question 3 — A ball's height is h(t) = −5t² + 25t (t ≥ 0). Find (a) the initial velocity, (b) the maximum height, (c) when it hits the ground and its velocity then.

(a) v(0) = 25 m/s. (b) v = 0 at t = 2.5; h(2.5) = 31.25 m. (c) h = 0 at t = 5; v(5) = −25 m/s.

Question 4 — For s(t) = 8 + 7t + t², find the velocity and acceleration at t = 5.

v(t) = 7 + 2t → v(5) = 17 m/s; a(t) = 2 m/s².

📝 Lesson Summary

Key ideas

  • v(t) = s′(t), a(t) = v′(t) = s″(t), speed = |v(t)|.
  • v > 0: moving right/up; v < 0: moving left/down; v = 0: stationary (possible direction change).

Need to know

  • Speeding up when v and a share a sign; slowing down when signs differ.
  • a = 0 means constant velocity at that instant.

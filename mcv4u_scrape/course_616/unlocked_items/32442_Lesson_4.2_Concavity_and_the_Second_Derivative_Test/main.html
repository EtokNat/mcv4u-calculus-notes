Concavity and the Second Derivative Test

Nelson Calculus and Vectors 12 §4.4 (part 1) — the sign of f″ tells how the curve bends; the second derivative test classifies critical points.

🎯 Learning Goals

By the end of this lesson, you can:

  • Determine concavity (up/down) from the sign of f″(x).
  • Relate concavity to whether the tangent slopes are increasing or decreasing.
  • Apply the second derivative test to classify local maxima and minima.

💡 Minds On

In Lesson 4.1 the first derivative told you whether the graph climbs or falls. But two graphs can both be climbing while bending in opposite ways — one curving upward like a bowl, the other arching over like a dome. The second derivative measures that bending. Today you will read concavity straight from the sign of f″, and you will gain a faster way to classify maxima and minima.

📖 Learn — step by step

Concave up vs concave down

Think of the tangent slopes as you move left to right. If the slopes are increasing (e.g. −3, −1, 0, 2, 5), the curve bends upward — it is concave up, shaped like a bowl that "holds water". If the slopes are decreasing, the curve bends downward — it is concave down, shaped like a dome that "spills water".

The second derivative f″ measures exactly this: it is the rate of change of the slopes. So:

  • If f″(x) > 0 on an interval, f is concave up there (the graph lies above its tangent lines).
  • If f″(x) < 0 on an interval, f is concave down there (the graph lies below its tangent lines).

The second derivative test

Suppose c is a critical number with f′(c) = 0 (a horizontal tangent). Zoom in: if the curve is concave up at c, it must lie above its horizontal tangent — so (c, f(c)) is a local minimum. If concave down, it lies below its tangent — a local maximum. This gives the second derivative test:

  • If f′(c) = 0 and f″(c) > 0 → local minimum at c.
  • If f′(c) = 0 and f″(c) < 0 → local maximum at c.
  • If f″(c) = 0 → the test is inconclusive (it could be a max, a min, or neither — use the first derivative test instead).

Example 1 — For f(x) = x³ − 3x² − 9x + 10, find the concavity intervals and classify the local extrema with the second derivative test.

Solution. Differentiate twice.
f′(x) = 3x² − 6x − 9 = 3(x − 3)(x + 1) → critical numbers x = −1 and x = 3.
f″(x) = 6x − 6 = 6(x − 1).

Concavity: f″(x) > 0 when x > 1 → concave up on (1, ∞); f″(x) < 0 when x < 1 → concave down on (−∞, 1).

Second derivative test:
• f″(−1) = −12 < 0 → local maximum at x = −1; f(−1) = −1 − 3 + 9 + 10 = 15.
• f″(3) = 12 > 0 → local minimum at x = 3; f(3) = 27 − 27 − 27 + 10 = −17.

Example 2 — Classify the critical point of f(x) = x⁴ at x = 0.

Solution.
f′(x) = 4x³ = 0 at x = 0, so x = 0 is a critical number.
f″(x) = 12x², so f″(0) = 0 → the second derivative test is inconclusive.
Fall back to the first derivative test: f′(x) = 4x³ is negative for x < 0 and positive for x > 0. The sign changes − → + → local minimum at (0, 0). (Indeed it is the absolute minimum.)

Lesson: f″(c) = 0 tells you nothing by itself — always have the first derivative test ready as a backup.

Example 3 — Use the second derivative test on f(x) = 2x³ − 9x² + 12x − 5.

Solution.
f′(x) = 6x² − 18x + 12 = 6(x − 1)(x − 2) → critical numbers x = 1 and x = 2.
f″(x) = 12x − 18.
• f″(1) = −6 < 0 → local maximum at x = 1; f(1) = 2 − 9 + 12 − 5 = 0.
• f″(2) = 6 > 0 → local minimum at x = 2; f(2) = 16 − 36 + 24 − 5 = −1.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 4.4 (concavity portion).

Question 1 — Find the concavity intervals of f(x) = x³ − 3x.

f′(x) = 3x² − 3; f″(x) = 6x. f″ > 0 when x > 0, f″ < 0 when x < 0. Concave down on (−∞, 0); concave up on (0, ∞).

Question 2 — Classify the critical point of f(x) = −x² + 4x − 1 with the second derivative test.

f′(x) = −2x + 4 = 0 at x = 2. f″(x) = −2 < 0 always → local maximum at x = 2; f(2) = −4 + 8 − 1 = 3. (The parabola opens downward, as expected.)

Question 3 — For f(x) = x⁵, the second derivative test fails at x = 0. Classify (0, 0) anyway.

f′(x) = 5x⁴, f″(x) = 20x³, so f″(0) = 0 — inconclusive. But f′(x) = 5x⁴ ≥ 0 on both sides of 0: no sign change → neither a max nor a min at (0, 0).

Question 4 — If f′(c) = 0 and f″(c) > 0, what does the graph look like near (c, f(c))? Explain in words.

The tangent is horizontal and the curve is concave up there, so the graph lies above its tangent near c — a bowl shape with (c, f(c)) as a local minimum.

📝 Lesson Summary

Key ideas

  • f″(x) > 0 → concave up (bowl, holds water, slopes increasing); f″(x) < 0 → concave down (dome, spills water, slopes decreasing).
  • Second derivative test: at a critical number with f′(c) = 0 — f″(c) > 0 gives a local min, f″(c) < 0 gives a local max, f″(c) = 0 is inconclusive.

Need to know

  • When the second derivative test fails (f″(c) = 0), use the first derivative test instead.

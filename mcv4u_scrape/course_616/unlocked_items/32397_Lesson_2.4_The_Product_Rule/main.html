The Product Rule

Nelson Calculus and Vectors 12 §2.3 — the derivative of a product is not the product of the derivatives.

🎯 Learning Goals

By the end of this lesson, you can:

  • Explain why (fg)′ ≠ f′g′ with a counterexample.
  • Apply the product rule, the extended product rule, and the power of a function rule (integer exponents).
  • Choose between expanding first and using the product rule.

💡 Minds On

You might suspect that the derivative of a product of two functions is simply the product of the separate derivatives. An example shows this is not so — and the correct rule is one of the most used in calculus.

📖 Learn — step by step

Example 1 — Let p(x) = f(x)g(x), where f(x) = x² + 2 and g(x) = x + 5. Show that p′(x) ≠ f′(x)g′(x).

Solution. The expression p(x) can be simplified:
p(x) = (x² + 2)(x + 5) = x³ + 5x² + 2x + 10, so p′(x) = 3x² + 10x + 2.
But f′(x) = 2x and g′(x) = 1, so f′(x)g′(x) = 2x.
Since 2x is not the derivative of p(x), we have shown p′(x) ≠ f′(x)g′(x).

The Product Rule. If p(x) = f(x)g(x), then p′(x) = f′(x)g(x) + f(x)g′(x). In Leibniz notation, if u and v are functions of x, d/dx(uv) = (du/dx)v + u(dv/dx).
In words: "the derivative of the product of two functions is the derivative of the first function times the second function plus the first function times the derivative of the second function."
Proof idea: in the difference quotient for p, subtract and add the same term f(x)g(x + h) in the numerator; regrouping and taking limits gives f′(x)g(x) + f(x)g′(x).

Example 2 — Differentiate h(x) = (x² − 3x)(x⁵ + 2) using the product rule.

Solution. h′(x) = d/dx[x² − 3x]·(x⁵ + 2) + (x² − 3x)·d/dx[x⁵ + 2]
= (2x − 3)(x⁵ + 2) + (x² − 3x)(5x⁴)
= 2x⁶ − 3x⁵ + 4x − 6 + 5x⁶ − 15x⁵
= 7x⁶ − 18x⁵ + 4x − 6.

Working smart. It is not necessary to simplify when asked for the derivative's value at a point — substitute into the unsimplified derivative instead. And sometimes expanding first is simpler than the product rule (but not for (x² + 9)(x³ + 5)⁴ or (x² + 9)√(x³ + 5)).

Example 3 — Find h′(−1) for h(x) = (5x³ + 7x² + 3)(2x² + x + 6).

Solution. By the product rule, h′(x) = (15x² + 14x)(2x² + x + 6) + (5x³ + 7x² + 3)(4x + 1). Substituting x = −1 without simplifying:
h′(−1) = [15(−1)² + 14(−1)][2(−1)² + (−1) + 6] + [5(−1)³ + 7(−1)² + 3][4(−1) + 1]
= (1)(7) + (5)(−3)
= −8.

Example 4 — Find an expression for p′(x) if p(x) = f(x)g(x)h(x).

Solution. Regard f(x)g(x) as a single function and apply the product rule twice:
p′(x) = [f(x)g(x)]′h(x) + [f(x)g(x)]h′(x) = [f′(x)g(x) + f(x)g′(x)]h(x) + f(x)g(x)h′(x)
= f′(x)g(x)h(x) + f(x)g′(x)h(x) + f(x)g(x)h′(x).
This is the extended product rule — its symmetrical form extends to four or more functions.

Functions like y = (x² − 3)⁴ or y = (x² + 3x + 5)⁶ have the form y = uⁿ with n a positive integer. Using the product rule on u·u, then u·u·u, suggests a generalization:

The Power of a Function Rule (Integers). If u is a function of x and n is an integer, then d/dx(uⁿ) = nuⁿ⁻¹·du/dx. (A special case of the chain rule — see Lesson 2.6.)

Example 5 — For h(x) = (x² + 3x + 5)⁶, find h′(x).

Solution. The "inner" function is g(x) = x² + 3x + 5. By the power of a function rule, h′(x) = 6(x² + 3x + 5)⁵(2x + 3).

Example 6 — Differentiate f(x) = (2x + 5)/(3x − 1) by first expressing it as a product, then using the product rule.

Solution. f(x) = (2x + 5)(3x − 1)⁻¹   (Express f as a product)
f′(x) = d/dx[(2x + 5)]·(3x − 1)⁻¹ + (2x + 5)·d/dx[(3x − 1)⁻¹]   (Product rule)
= 2(3x − 1)⁻¹ + (2x + 5)(−1)(3x − 1)⁻²·d/dx(3x − 1)   (Power of a function rule)
= 2(3x − 1)⁻¹ − 3(2x + 5)(3x − 1)⁻²
= 2/(3x − 1) − 3(2x + 5)/(3x − 1)²   (Simplify)
= [2(3x − 1) − (6x + 15)]/(3x − 1)²
= (6x − 2 − 6x − 15)/(3x − 1)²
= −17/(3x − 1)².

Example 7 — The position s, in centimetres, of an object moving in a straight line is s = t(6 − 3t)⁴, t ≥ 0, with t in seconds. Determine the object's velocity at t = 2.

Solution. v = ds/dt = d/dt[t(6 − 3t)⁴]
= (1)(6 − 3t)⁴ + (t)·d/dt[(6 − 3t)⁴]   (Product rule)
= (6 − 3t)⁴ + (t)[4(6 − 3t)³(−3)]   (Power of a function rule)
At t = 2: v = 0 + (2)[4(0)(−3)] = 0.
The object is at rest at t = 2 s.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 2.3.

Question 1 — Differentiate x(x − 4) and x²(2x − 1) using the product rule.

x(x − 4): (1)(x − 4) + x(1) = 2x − 4. x²(2x − 1): (2x)(2x − 1) + x²(2) = 6x² − 2x.

Question 2 — Find dy/dx at x = 2 for y = (2 + 7x)(x − 3).

y′ = 7(x − 3) + (2 + 7x)(1) = 14x − 19; at x = 2: 9.

Question 3 — When is the product rule NOT appropriate? Give an example.

When the expression is not a product — e.g., a sum like x² + 3x (use the sum rule), or a single power like x⁵ (use the power rule).

Question 4 — Find the tangent to y = (x³ − 5x + 2)(3x² − 2x) at (1, −2).

y′ = (3x² − 5)(3x² − 2x) + (x³ − 5x + 2)(6x − 2); at x = 1: (−2)(1) + (−2)(4) = −10. Tangent: y + 2 = −10(x − 1), or y = −10x + 8.

📝 Lesson Summary

Key ideas

  • Product rule: (fg)′ = f′g + fg′.
  • Extended product rule: (fgh)′ = f′gh + fg′h + fgh′.
  • Power of a function (integer n): d/dx(uⁿ) = nuⁿ⁻¹·du/dx.

Need to know

  • The derivative of a product is not the product of the derivatives.
  • Expand first when it is easy; use the rule when it is not.
  • For a value at a point, substitute into the unsimplified derivative.

🎯 Learning Goals

  • Find the angle between vectors from components using θ = cos⁻¹((a·b)/(|a||b|)).
  • Test perpendicularity algebraically: nonzero vectors are perpendicular ⟺ a·b = 0.

📖 Learn — step by step

The component formula

An algebraic vector is a vector written as an ordered list of components, such as a = (−1, 2, 4) in R³. The dot product has a beautifully simple component form:

a · b = a₁b₁ + a₂b₂ + a₃b₃

Multiply matching components, then add. In R² it is the same idea with two terms: (a₁, a₂)·(b₁, b₂) = a₁b₁ + a₂b₂. The sum of ordinary numbers is an ordinary number — so the dot product of algebraic vectors is visibly a scalar, exactly as Lesson 7.1 required.

Why the formula is true

Place a = (a₁, a₂, a₃) and b = (b₁, b₂, b₃) with their tails at the origin, and look at the triangle with vertices O, A (tip of a), and B (tip of b). The side AB is the vector b − a = (b₁−a₁, b₂−a₂, b₃−a₃). The cosine law on this triangle gives |AB|² = |a|² + |b|² − 2|a||b|cosθ. Expanding the left side in components and cancelling the matching |a|² and |b|² terms on the right leaves −2(a₁b₁ + a₂b₂ + a₃b₃) = −2|a||b|cosθ = −2(a·b). Divide by −2 and the component formula appears. The same argument works in R².

Properties re-proven in one line

With components, the old properties become facts about real-number arithmetic:

  • Commutative: a₁b₁ + a₂b₂ + a₃b₃ = b₁a₁ + b₂a₂ + b₃a₃, because ordinary multiplication commutes.
  • Distributive: expanding a·(b + c) component by component gives a₁(b₁+c₁) + … = (a·b) + (a·c).
  • a·a = |a|²: a₁² + a₂² + a₃² is exactly the squared magnitude. So the magnitude is |a| = √(a·a).
  • Unit vectors: the standard unit vectors i = (1, 0, 0), j = (0, 1, 0), k = (0, 0, 1) satisfy i·i = j·j = k·k = 1 and i·j = j·k = k·i = 0.
Key term — Angle formula: rearranging a·b = |a||b|cosθ gives cosθ = (a·b)/(|a||b|), so θ = cos⁻¹((a·b)/(|a||b|)). This finds the angle between any two algebraic vectors, always returning a value between 0° and 180°.

Example 1 — Given a = (−1, 2, 4) and b = (3, 4, 3): (a) calculate a·b; (b) find the angle between them (nearest 0.1°).

(a) a·b = (−1)(3) + (2)(4) + (4)(3) = −3 + 8 + 12 = 17.
(b) |a| = √((−1)² + 2² + 4²) = √21 ≈ 4.583; |b| = √(3² + 4² + 3²) = √34 ≈ 5.831. Then cosθ = 17/(√21·√34) ≈ 17/26.721 ≈ 0.6362, so θ ≈ 50.5°.

Example 2 — For what value(s) of k are the vectors a = (−1, 3, −4) and b = (3, k, −2) perpendicular?

Perpendicular ⟺ dot product zero: a·b = (−1)(3) + (3)(k) + (−4)(−2) = −3 + 3k + 8 = 5 + 3k. Setting 5 + 3k = 0 gives k = −5/3.

Example 3 — A parallelogram has its sides determined by a = (6, 1) and b = (−1, 3). Find its two diagonals and the angle between the sides.

The diagonals are a + b = (5, 4) and a − b = (7, −2). For the angle between the sides: a·b = (6)(−1) + (1)(3) = −3; |a| = √37 ≈ 6.083; |b| = √10 ≈ 3.162. So cosθ = −3/(√37·√10) ≈ −3/19.235 ≈ −0.1560, giving θ ≈ 99.0° — the negative dot product confirms an obtuse angle.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 7.4 and the Mid-Chapter Review.

Question 1 — For a = (4, −5, 2) and b = (1, 2, 2), find a·b.

a·b = (4)(1) + (−5)(2) + (2)(2) = 4 − 10 + 4 = −2.

Question 2 — Find the cosine of the angle between a = (4, −5, 2) and b = (1, 2, 2), then the angle (nearest degree).

|a| = √(16+25+4) = √45 = 3√5; |b| = √(1+4+4) = 3. cosθ = −2/(3·3√5) = −2/(9√5) ≈ −0.0994, so θ ≈ 96°.

Question 3 — For what value of k are u = (k, 2, −1) and v = (2, 1, k) perpendicular?

u·v = 2k + 2 − k = k + 2 = 0, so k = −2.

Question 4 — Why does the algebraic formula guarantee that a·b = b·a?

Both equal a₁b₁ + a₂b₂ + a₃b₃ = b₁a₁ + b₂a₂ + b₃a₃ — the sums of ordinary products are identical because real-number multiplication commutes.

📝 Lesson Summary

Key ideas

  • a·b = a₁b₁ + a₂b₂ + a₃b₃ — multiply matching components, then add.
  • θ = cos⁻¹((a·b)/(|a||b|)) finds the angle from components alone.
  • Nonzero vectors are perpendicular ⟺ a·b = 0 — now checkable with coordinates.

Need to know

  • |a| = √(a·a) — magnitude is the square root of the self dot product.
  • The component formula re-proves commutativity and distributivity from real-number arithmetic.

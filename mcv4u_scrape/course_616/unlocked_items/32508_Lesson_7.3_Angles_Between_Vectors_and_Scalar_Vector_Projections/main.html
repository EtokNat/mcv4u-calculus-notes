LESSON 7.3

Angles Between Vectors and Scalar/Vector Projections

Nelson Calculus and Vectors 12 §§7.3–7.5 — reading the angle, then splitting a vector into a shadow and a remainder.

🎯 Learning Goals

By the end of this lesson, you can:

  • Find the angle between any two vectors (always 0° to 180°) and classify it as acute, right, or obtuse.
  • Compute the scalar projection of a onto b: (a·b)/|b| = |a|cosθ (a signed length).
  • Compute the vector projection of a onto b: ((a·b)/|b|²) b (the "shadow" vector).
  • Split any vector a into a parallel part (its projection) and a perpendicular remainder.

💡 Minds On

At noon a flagpole's shadow is a dot; at sunset it stretches long across the lawn. The shadow is the pole projected onto the ground — its length depends on the sun's angle. The dot product does the same thing for vectors: it projects one vector onto another, telling you exactly how much of the first vector "lies along" the second.

  3. Check the leftover: define r=(a[1]-p[1],a[2]-p[2]) and compute r[1]b[1]+r[2]b[2] — it equals 0. Conclusion: every vector splits into a part along b (the projection) and a part perpendicular to b.

📖 Learn — step by step

The angle between vectors

From a·b = |a||b|cosθ comes the angle formula:

θ = cos⁻¹( (a·b) / (|a| |b|) ),   0° ≤ θ ≤ 180°

Because the inverse cosine always returns a value between 0° and 180°, this is the angle between the vectors — no sign ambiguity. The classification is instant:

  • a·b > 0 → θ acute (0° < θ < 90°)
  • a·b = 0 → θ = 90° (perpendicular)
  • a·b < 0 → θ obtuse (90° < θ < 180°)

Scalar projection: how much of a lies along b

Drop a perpendicular from the tip of a onto the line of b (tails together). The signed length of the resulting "shadow" along b is the scalar projection of a onto b. From the right triangle, that length is |a|cosθ — and dividing a·b = |a||b|cosθ by |b| gives it directly:

scalar projection of a onto b = (a·b) / |b| = |a| cosθ

It is signed: positive when θ is acute (the shadow falls the same way b points), negative when θ is obtuse (the shadow falls the opposite way), and zero when the vectors are perpendicular. Note the asymmetry: projecting a onto b is generally different from projecting b onto a — the answer is always measured along the second vector.

Vector projection: the shadow as a vector

The shadow itself, as a vector pointing along b, is the vector projection. Take the scalar projection (a length) and aim it along b by multiplying by the unit vector in b's direction, b̂ = b/|b|:

projb a = ( (a·b) / |b|² ) b

This is the parallel part of a relative to b. Everything left over, a − projb a, is perpendicular to b — a fact you can verify with one dot product. So every vector splits cleanly: a = (parallel part) + (perpendicular part).

Example 1 — Find the angle between a = (2, 3) and b = (5, −1), to the nearest 0.1°, and classify it.

a·b = (2)(5) + (3)(−1) = 10 − 3 = 7. |a| = √13 ≈ 3.606; |b| = √26 ≈ 5.099. cosθ = 7/(√13·√26) = 7/√338 ≈ 0.3809, so θ ≈ 67.6° — acute, consistent with the positive dot product.

Example 2 — Find the scalar and vector projections of a = (2, 3) onto b = (5, −1).

Scalar projection = (a·b)/|b| = 7/√26 ≈ 1.373. Vector projection = ((a·b)/|b|²) b = (7/26)(5, −1) = (35/26, −7/26) ≈ (1.346, −0.269).

Example 3 — Split a = (2, 3) into parts parallel and perpendicular to b = (5, −1), and verify the split.

Parallel part = projb a = (35/26, −7/26). Perpendicular remainder = a − projb a = (2 − 35/26, 3 + 7/26) = (17/26, 85/26). Check: (17/26)(5) + (85/26)(−1) = 85/26 − 85/26 = 0, so the remainder is perpendicular to b, as required. And (35/26 + 17/26, −7/26 + 85/26) = (52/26, 78/26) = (2, 3) = a. ✓

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on §7.5-style projection problems.

Question 1 — Find the angle between u = (1, 0, −1) and v = (0, 1, 1), to the nearest degree.

u·v = 0 + 0 − 1 = −1; |u| = √2; |v| = √2. cosθ = −1/2, so θ = 120° (obtuse).

Question 2 — Find the scalar projection of a = (3, −4) onto b = (1, 1).

a·b = 3 − 4 = −1; |b| = √2. Scalar projection = −1/√2 = −√2/2 ≈ −0.707. The negative sign says the shadow falls opposite to b's direction.

Question 3 — Find the vector projection of a = (3, −4) onto b = (1, 1).

projb a = ((a·b)/|b|²) b = (−1/2)(1, 1) = (−1/2, −1/2).

Question 4 — True or false: the scalar projection of a onto b is always positive.

False. It is |a|cosθ, which is negative when θ is obtuse (see Question 2) and zero when the vectors are perpendicular.

📝 Lesson Summary

Key ideas

  • θ = cos⁻¹((a·b)/(|a||b|)) — the angle, always 0° to 180°; its type follows the sign of a·b.
  • Scalar projection (signed length): (a·b)/|b| = |a|cosθ.
  • Vector projection (the shadow vector): ((a·b)/|b|²) b.

Need to know

  • Projection is not symmetric: projecting a onto b differs from projecting b onto a.
  • Every vector splits: a = projb a + (a − projb a), parallel part plus perpendicular remainder.

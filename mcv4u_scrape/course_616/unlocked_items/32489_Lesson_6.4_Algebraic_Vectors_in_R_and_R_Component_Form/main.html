Algebraic Vectors in R² and R³: Component Form

Nelson Calculus and Vectors 12 §6.5 — from arrows to coordinates: position vectors.

🎯 Learning Goals

By the end of this lesson, you can:

  • Locate points and position vectors in R² and R³, reading coordinates off a box diagram.
  • Write a vector in component form (a, b) or (a, b, c) and sketch it from its components.
  • Describe planes in R³ with simple equations (z = 0, y = −3, …).

💡 Minds On

Geometric vectors are elegant but hard to compute with — every addition needs a fresh diagram. Coordinates fix that: once an arrow becomes a list of numbers, adding vectors becomes adding numbers. Today the arrow moves onto graph paper, first in the plane (R²), then in space (R³).

🔍 Explore — components are just steps

  1. In Desmos, plot (0,0) and (4,3). The arrow between them is the position vector (4, 3): 4 steps in x, 3 steps in y.
  2. Its length is sqrt(4^2+3^2) = 5 — the 3-4-5 triangle hiding inside every (4, 3) vector.
  3. Plot (-2,5) as well. Negative components just mean stepping left or down. Conclusion: components record the signed journey from tail to head.

📖 Learn — step by step

Key term — Position vector: the vector OP with its tail at the origin O and its head at point P. In R², OP = (a, b) for P(a, b); in R³, OP = (a, b, c) for P(a, b, c).
  • R²: the plane. R² is the set of all ordered pairs (x, y) — the ordinary xy-plane. The position vector OP = (a, b) is the arrow from (0, 0) to (a, b). Because every point sits in exactly one place, every position vector is unique: equal components mean equal vectors.
  • R³: space. R³ is the set of all ordered triples (x, y, z). The three axes are mutually perpendicular and form a right-handed system (curl x toward y and your thumb points along +z). To find P(a, b, c): walk a units along x, then b units parallel to y, then c units parallel to z — you land on the corner of a rectangular box.
  • Reading the box. Each vertex of the box zeroes out some coordinates: (a, 0, 0) is on the x-axis, (a, b, 0) is on the xy-plane, (0, b, c) is on the yz-plane, and so on. A zero coordinate means "no step in that direction."
  • Planes as equations. The xy-plane is simply z = 0 — every point (x, y, 0). A plane parallel to it through (0, 0, −5) is z = −5. Similarly, y = −3 is the plane of all points (x, −3, z).

Example 1 — The point P(6, 2, 4) sits in R³. Name the coordinates of the box corners: A on the x-axis, B on the xy-plane, C on the xz-plane, D on the z-axis, E on the yz-plane, F on the y-axis. Then write OP.

Solution. Zero out coordinates to land on each axis or plane:
A = (6, 0, 0) (x-axis), B = (6, 2, 0) (xy-plane), C = (6, 0, 4) (xz-plane), D = (0, 0, 4) (z-axis), E = (0, 2, 4) (yz-plane), F = (0, 2, 0) (y-axis).
The position vector is OP = (6, 2, 4).

Example 2 — T is (−3, 2, −2) in R³. (a) Give the coordinates of M on the negative x-axis, N on the xz-plane, and S on the xy-plane. (b) Write OT.

Solution.
(a) M = (−3, 0, 0), N = (−3, 0, −2), S = (−3, 2, 0) — signed coordinates work the same way in every octant.
(b) OT = (−3, 2, −2).

Example 3 — (a) Write an equation for the xy-plane. (b) Write an equation for the plane through R(0, 0, −5) parallel to the xy-plane.

Solution.
(a) Every point of the xy-plane has z-coordinate 0, so the equation is z = 0 — the set of all (x, y, 0).
(b) A parallel plane keeps z constant at −5: z = −5 — the set of all (x, y, −5).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 6.5.

Question 1 — OP = (a, −3, c) and OP = (−4, b, −8) describe the same vector. Find a, b, c.

Equal vectors have equal components: a = −4, b = −3, c = −8 — the representation is unique, so matching component-by-component is valid.

Question 2 — On which axis does A(0, −1, 0) lie? Name the vector OA.

Only the y-coordinate is nonzero, so A is on the y-axis; OA = (0, −1, 0).

Question 3 — Name the three coordinate planes that contain P(x, y, 0), Q(x, 0, z), and R(0, y, z) respectively.

P is on the xy-plane (z = 0); Q is on the xz-plane (y = 0); R is on the yz-plane (x = 0).

Question 4 — Why is OP = (−2, 4, −√3) acceptable in R³ but not in I³ (integer triples)?

R³ allows any real components, and −√3 is real. I³ allows only integers, and −√3 is not one — so the vector is rejected there.

📝 Lesson Summary

Key ideas

  • Position vector OP: tail at the origin, head at P — unique for every point.
  • R²: OP = (a, b); R³: OP = (a, b, c) with a right-handed axis system; read box corners by zeroing coordinates.
  • Coordinate planes: xy is z = 0; parallel planes fix one coordinate.

Need to know

  • When a problem says "vector," assume component form unless it says otherwise — that's the algebraic vector.

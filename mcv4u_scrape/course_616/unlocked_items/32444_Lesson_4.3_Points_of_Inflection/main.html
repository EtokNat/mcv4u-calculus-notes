💡 Minds On

Picture driving along a winding road: first you steer left through a left-hand bend, then the road straightens for an instant, then you steer right. That instant — where the bending reverses — is the inflection point of your path. On a graph, a point of inflection is exactly that moment: the curve stops bending one way and starts bending the other. Today you will learn to find those moments with the second derivative.

📖 Learn — step by step

What an inflection point is

A point of inflection is a point on the graph where the concavity changes — from concave up to concave down, or from concave down to concave up. Since concavity is controlled by the sign of f″, an inflection point can only occur where f″ changes sign. The candidates are x-values where f″(x) = 0 or where f″(x) is undefined (provided f itself is defined there — an inflection point must be an actual point on the graph).

The crucial caution: f″(c) = 0 is not enough. The sign must genuinely change. The classic counterexample is y = x⁴: f″(x) = 12x² equals 0 at x = 0, but f″ is positive on both sides — no sign change, no inflection point (the origin is a minimum instead).

Example 1 — Find the inflection point(s) of f(x) = x³ − 3x² − 9x + 10.

Solution. Differentiate twice and look for sign changes of f″.
f′(x) = 3x² − 6x − 9
f″(x) = 6x − 6 = 6(x − 1)
f″(x) = 0 at x = 1. Sign check: for x < 1, f″ < 0 (concave down); for x > 1, f″ > 0 (concave up). The sign changes, so there is an inflection point at x = 1.
f(1) = 1 − 3 − 9 + 10 = −1. The inflection point is (1, −1).

Example 2 — Find the inflection points of f(x) = 1/(x² + 3).

Solution.
f′(x) = −2x/(x² + 3)²   (quotient rule)
f″(x) = [−2(x² + 3)² − (−2x)·2(x² + 3)·2x]/(x² + 3)⁴
= [−2(x² + 3) + 8x²]/(x² + 3)³
= (6x² − 6)/(x² + 3)³

The denominator is always positive, so the sign of f″ is the sign of 6x² − 6 = 6(x − 1)(x + 1), which is zero at x = ±1:
• |x| > 1: f″ > 0 → concave up
• |x| < 1: f″ < 0 → concave down
The sign changes at both x = 1 and x = −1. Since f(1) = f(−1) = 1/4, the inflection points are (1, 1/4) and (−1, 1/4).

Inflection where f″ is undefined

Sign changes can also happen where the second derivative doesn't exist. For f(x) = ∛x = x^(1/3): f″(x) = (−2/9)x^(−5/3), undefined at x = 0. For x > 0, f″ < 0 (concave down); for x < 0, f″ > 0 (concave up). The concavity changes and (0, 0) is on the graph, so (0, 0) is an inflection point — with a vertical tangent there.

Example 3 — Show that (0, 0) is an inflection point of f(x) = ∛x.

Solution.
f(x) = x^(1/3) → f′(x) = (1/3)x^(−2/3) → f″(x) = (−2/9)x^(−5/3).
f″ is undefined at x = 0, so x = 0 is a candidate. Check the sign:
• x > 0: x^(−5/3) > 0, so f″(x) = (−2/9)(positive) < 0 → concave down
• x < 0: x^(−5/3) < 0, so f″(x) = (−2/9)(negative) > 0 → concave up
The sign changes and f(0) = 0 exists → (0, 0) is an inflection point (with a vertical tangent, since f′(x) → ∞ as x → 0).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 4.4 (inflection portion).

Question 1 — Find the inflection point of f(x) = x³ − 6x² + 9x − 4.

f″(x) = 6x − 12 = 6(x − 2); zero at x = 2 with a sign change (− → +). f(2) = 8 − 24 + 18 − 4 = −2. The inflection point is (2, −2).

Question 2 — Show that f(x) = x⁴ + 2x² + 1 has no inflection points.

f″(x) = 12x² + 4, which is positive for every x — it never equals zero and never changes sign. The curve is always concave up, so there are no inflection points.

Question 3 — True or false: "If f″(c) = 0 then (c, f(c)) is an inflection point." Justify.

False. Counterexample: f(x) = x⁴ has f″(0) = 0, but f″(x) = 12x² ≥ 0 on both sides — no sign change, so (0, 0) is a minimum, not an inflection point. You must check the sign change.

Question 4 — Find the inflection point of f(x) = x³ + 3x² + 3x + 1.

Notice f(x) = (x + 1)³. f′(x) = 3(x + 1)²; f″(x) = 6(x + 1); zero at x = −1 with sign change (− → +). f(−1) = 0. The inflection point is (−1, 0).

📝 Lesson Summary

Key ideas

  • A point of inflection is a point on the graph where concavity changes — equivalently, where f″ changes sign.
  • Candidates: x-values where f″(x) = 0 or f″(x) is undefined (and f is defined there).
  • f″(c) = 0 alone proves nothing — always verify the sign change (y = x⁴ is the standard counterexample).

Need to know

  • An inflection point is a point (c, f(c)), not just an x-value — compute the y-coordinate.

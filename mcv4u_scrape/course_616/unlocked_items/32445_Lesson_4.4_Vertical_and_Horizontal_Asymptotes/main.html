Vertical and Horizontal Asymptotes

Nelson Calculus and Vectors 12 §4.3 — lines the graph can approach but never reach: infinite limits and limits at infinity.

🎯 Learning Goals

By the end of this lesson, you can:

  • Find vertical asymptotes using one-sided infinite limits.
  • Find horizontal asymptotes using limits at infinity (including the degree-comparison shortcut).
  • Find oblique (slant) asymptotes by polynomial division.

💡 Minds On

Some graphs have invisible "guard rails" — straight lines the curve races toward but never touches. Near x = 2, the graph of y = 1/(x − 2) shoots off to infinity; far out at x = ±1000, the graph of y = (2x − 3)/(x + 1) settles down toward the line y = 2. These guard rails are asymptotes, and limits are the tool that finds them. Master them here and the full curve sketches of Lesson 4.5 become straightforward.

📖 Learn — step by step

Vertical asymptotes: infinite limits

The line x = a is a vertical asymptote if |f(x)| → ∞ as x → a (from the left, the right, or both). For a rational function, this typically happens at x-values where the denominator is zero but the numerator is not. Always check both one-sided limits — the curve may shoot to +∞ on one side and −∞ on the other.

Example 1 — Find the vertical asymptote(s) of f(x) = 1/(x − 2) and describe the behaviour near them.

Solution. The denominator is zero at x = 2 while the numerator is 1 ≠ 0, so x = 2 is a vertical asymptote. One-sided limits:
• As x → 2⁺ (e.g. 2.001): x − 2 is a tiny positive number → 1/(x − 2) → +∞.
• As x → 2⁻ (e.g. 1.999): x − 2 is a tiny negative number → 1/(x − 2) → −∞.
The curve plunges down on the left of x = 2 and soars up on the right.

Horizontal asymptotes: limits at infinity

The line y = L is a horizontal asymptote if lim(x→+∞) f(x) = L or lim(x→−∞) f(x) = L (or both). For a rational function f(x) = P(x)/Q(x), compare degrees:

  • deg P < deg Q → HA is y = 0 (the denominator wins).
  • deg P = deg Q → HA is y = (leading coefficient of P)/(leading coefficient of Q).
  • deg P > deg Q → no horizontal asymptote (if deg P = deg Q + 1, there is an oblique asymptote — see below).

To tell which side the curve approaches from, compute f(x) − L and check its sign for large |x|. A graph can cross its horizontal asymptote at finite x-values — the asymptote only controls the far ends.

Example 2 — Find the asymptotes of f(x) = (2x − 3)/(x + 1), and tell from which side the curve approaches the horizontal asymptote as x → ±∞.

Solution.
Vertical: denominator zero at x = −1, numerator −5 ≠ 0 → VA: x = −1.
Horizontal: degrees are equal (1 = 1) → HA: y = 2/1 = 2.
Which side? Compute the difference:
f(x) − 2 = (2x − 3)/(x + 1) − 2 = [(2x − 3) − 2(x + 1)]/(x + 1) = −5/(x + 1).
• As x → +∞: −5/(x + 1) is negative and tiny → curve approaches y = 2 from below.
• As x → −∞: −5/(x + 1) is positive and tiny → curve approaches y = 2 from above.

Oblique asymptotes: division

When deg P = deg Q + 1, long division writes f(x) = (mx + b) + remainder/Q(x). As x → ±∞, the remainder term vanishes, so the graph approaches the slanted line y = mx + b — an oblique (slant) asymptote.

Example 3 — Find all asymptotes of f(x) = (2x² + 3x − 1)/(x + 1).

Solution.
Vertical: x + 1 = 0 at x = −1, numerator 2 − 3 − 1 = −2 ≠ 0 → VA: x = −1.
Horizontal: deg numerator (2) > deg denominator (1) → no horizontal asymptote. Since 2 = 1 + 1, divide:
(2x² + 3x − 1) ÷ (x + 1): 2x² ÷ x = 2x; 2x(x + 1) = 2x² + 2x; subtract → x − 1. Then x ÷ x = +1; 1(x + 1) = x + 1; subtract → remainder −2.
So f(x) = 2x + 1 − 2/(x + 1). As x → ±∞, 2/(x + 1) → 0, so the graph approaches the line y = 2x + 1 — the oblique asymptote.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 4.3.

Question 1 — Find the vertical asymptotes of f(x) = (x + 1)/(x² − 9).

x² − 9 = 0 at x = ±3; the numerator is nonzero at both (±3 + 1 ≠ 0). Vertical asymptotes: x = 3 and x = −3.

Question 2 — State the horizontal asymptote of f(x) = (5x³ − 2x)/(3x³ + x²).

Degrees are equal (3 = 3) → y = 5/3 (ratio of leading coefficients).

Question 3 — State the horizontal asymptote of f(x) = (4x² + 1)/(2x³ − x).

Degree of numerator (2) < degree of denominator (3) → the denominator wins → y = 0.

Question 4 — Find the oblique asymptote of f(x) = (x² + 3x + 5)/(x + 1).

Divide: (x² + 3x + 5) ÷ (x + 1) = x + 2 with remainder 3, so f(x) = x + 2 + 3/(x + 1). As x → ±∞, the fraction vanishes → oblique asymptote: y = x + 2.

📝 Lesson Summary

Key ideas

  • Vertical asymptote x = a: |f(x)| → ∞ as x → a — usually where the denominator is zero and the numerator isn't.
  • Horizontal asymptote y = L: lim(x→±∞) f(x) = L. Degree shortcut: lower → y = 0; equal → ratio of leading coefficients; higher → none.
  • Oblique asymptote: when deg P = deg Q + 1, divide — the quotient line y = mx + b is the asymptote.

Need to know

  • A graph cannot cross a vertical asymptote but can cross a horizontal one.

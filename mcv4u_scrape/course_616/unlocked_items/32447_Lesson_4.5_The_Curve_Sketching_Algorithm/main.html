📖 Learn — step by step

The six-step algorithm

  1. Domain and intercepts. Where is f defined? Find the y-intercept f(0) and the x-intercepts (solve f(x) = 0).
  2. Symmetry. Even (f(−x) = f(x), mirror in the y-axis), odd (f(−x) = −f(x), rotational symmetry about the origin), or neither — symmetry halves the work.
  3. Asymptotes. Vertical (denominator zero), horizontal (limits at infinity), oblique (division). Draw them as dashed guides first for rational functions.
  4. Increase/decrease and extrema. Sign chart of f′ → intervals of increase/decrease; first or second derivative test → local maxima/minima.
  5. Concavity and inflection. Sign chart of f″ → concave up/down intervals; sign changes → inflection points.
  6. Assemble. Plot the intercepts, extrema, and inflection points; add the asymptotes; join everything with smooth branches that respect every sign chart.

Example 1 — Sketch f(x) = x³ − 3x using the algorithm.

Solution.
1. Domain & intercepts: all real numbers. f(0) = 0. x-intercepts: x³ − 3x = x(x² − 3) = 0 → x = 0, x = ±√3 ≈ ±1.73.
2. Symmetry: f(−x) = −x³ + 3x = −f(x) → odd; the graph has rotational symmetry about the origin.
3. Asymptotes: none (polynomial).
4. f′ analysis: f′(x) = 3x² − 3 = 3(x − 1)(x + 1); critical numbers x = ±1. Sign: + on (−∞, −1), − on (−1, 1), + on (1, ∞). Increasing on (−∞, −1) and (1, ∞); decreasing on (−1, 1). Local max (−1, 2); local min (1, −2).
5. f″ analysis: f″(x) = 6x; concave down on (−∞, 0), concave up on (0, ∞). Inflection point (0, 0).
6. Assemble: plot (−1.73, 0), (−1, 2), (0, 0), (1, −2), (1.73, 0) and join smoothly, respecting the rise/fall and bending on each interval.

Example 2 — Sketch f(x) = 2x²/(x² − 1) using the algorithm.

Solution.
1. Domain & intercepts: x ≠ ±1. f(0) = 0 → the only intercept is (0, 0) (numerator zero only at x = 0).
2. Symmetry: f(−x) = f(x) → even; mirror image in the y-axis.
3. Asymptotes: denominator zero at x = ±1 (numerator ≠ 0) → VAs: x = 1, x = −1. Degrees equal → HA: y = 2/1 = 2. Side check: f(x) − 2 = 2/(x² − 1) > 0 for |x| > 1 → the outer branches approach y = 2 from above.
4. f′ analysis: f′(x) = [4x(x² − 1) − 2x²(2x)]/(x² − 1)² = −4x/(x² − 1)². Critical number: x = 0 (x = ±1 are not in the domain). Sign: + on (−∞, −1) and (−1, 0); − on (0, 1) and (1, ∞). Increasing on (−∞, −1), (−1, 0); decreasing on (0, 1), (1, ∞). + → − at x = 0 → local maximum (0, 0).
5. f″ analysis: f″(x) = 4(3x² + 1)/(x² − 1)³. The numerator is always positive; the sign follows (x² − 1)³: concave up for |x| > 1, concave down for |x| < 1. The sign changes only at the asymptotes (not in the domain) → no inflection points.
6. Assemble: draw the dashed asymptotes first. Near x = 1: x → 1⁻ gives −∞ (denominator tiny negative), x → 1⁺ gives +∞. Near x = −1: x → −1⁻ gives +∞, x → −1⁺ gives −∞. Place the local max (0, 0), then draw three smooth branches hugging the guard rails.

Question 1 — List the six steps of the curve sketching algorithm in order.

1. Domain and intercepts. 2. Symmetry. 3. Asymptotes. 4. Intervals of increase/decrease and local extrema (f′). 5. Concavity and inflection points (f″). 6. Assemble the sketch.

Question 2 — For f(x) = (x − 1)/(x + 2), give the domain, asymptotes, and intercepts.

Domain: x ≠ −2. VA: x = −2. HA: y = 1 (equal degrees). Intercepts: f(0) = −1/2 → (0, −1/2); f(x) = 0 at x = 1 → (1, 0).

Question 3 — Find the local extrema of f(x) = x⁴ − 8x² + 16.

f′(x) = 4x³ − 16x = 4x(x − 2)(x + 2); critical numbers x = 0, ±2. f″(x) = 12x² − 16: f″(2) = f″(−2) = 32 > 0 → local minima at (±2, 0); f″(0) = −16 < 0 → local maximum at (0, 16). (Note f(x) = (x² − 4)² ≥ 0, so the minima are absolute.)

Question 4 — True or false: "A rational function can cross its horizontal asymptote." Give an example or explain.

True. Example: f(x) = x/(x² + 1) has HA y = 0 (degree 1 < 2) and crosses it at the origin, since f(0) = 0. The asymptote only controls behaviour as x → ±∞.

📝 Lesson Summary

Key ideas

  • The six steps: domain/intercepts → symmetry → asymptotes → f′ (increase/decrease, extrema) → f″ (concavity, inflection) → assemble.
  • For rational functions, draw the asymptotes first — they are the guard rails every branch must respect.
  • Symmetry (even/odd) can halve the computation.

Need to know

  • Every sign chart must include domain breaks (asymptotes) as dividers, not just critical numbers.

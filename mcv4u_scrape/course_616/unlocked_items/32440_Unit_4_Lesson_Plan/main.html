UNIT 4 LESSON PLAN

Curve Sketching

Course: MCV4U, Grade 12 Calculus and Vectors  |  Unit: 4 — Curve Sketching (Nelson Ch. 4)  |  Time: 12–14 periods (~75 min each)

Curriculum expectations (Strand B — Characteristics of Functions)

  • B3.1 — Determine intervals of increase/decrease for polynomial and rational functions using the sign of the first derivative; identify and classify critical points with the first derivative test (4.1).
  • B3.2 — Determine concavity intervals from the sign of the second derivative; apply the second derivative test to classify local extrema (4.2).
  • B3.3 — Identify points of inflection as points where concavity changes (sign change of f″), including cases where f″ is undefined (4.3).
  • B3.4 — Determine vertical asymptotes via infinite (one-sided) limits, horizontal asymptotes via limits at infinity, and oblique asymptotes via polynomial division (4.4).
  • B3.5 — Sketch polynomial and rational functions using the six-step algorithm (domain/intercepts, symmetry, asymptotes, f′ analysis, f″ analysis, assemble), with all key features labelled (4.5).
  • B3.6 — Interpret local extrema and inflection points in applied contexts and connect curve sketching to optimization models (4.6).

🎯 Learning Goals

Students will map increase/decrease and classify local extrema with the first derivative test; map concavity and inflection points with the second derivative; find all three asymptote types with limits; execute the six-step sketching algorithm on polynomial and rational functions to produce accurate labelled graphs; and interpret extrema and inflection points on applied graphs (buy/sell/trend-change decisions, diminishing returns).

Success criteria

  • I can build a sign chart for f′ (including points where f′ is undefined and where f is undefined) and read every interval of increase/decrease off it.
  • I can state the first derivative test (+ → − = max, − → + = min, no change = neither) and give a counterexample (y = x³) to "f′(c) = 0 ⟹ extremum".
  • I can build a sign chart for f″, state concavity on each interval, and verify the sign change before naming an inflection point (y = x⁴ is not one).
  • I can find vertical asymptotes (with one-sided behaviour), horizontal asymptotes (with the degree shortcut and the from-which-side check), and oblique asymptotes (by division).
  • I can run all six algorithm steps in order on a new function and produce a labelled sketch that honours every feature.
  • I can explain what a local max, local min, and inflection point mean on an applied graph.

Assessment plan

  • For learning: Entry Card (prior knowledge: derivative–graph link; confidence; goals), Formative Checks A/B/C with answer-specific feedback.
  • As learning: Exit Card (self-assessment, what clicked, what needs review, summative readiness), Unit 4 Discussion (peer explanation of buy/sell/inflection reasoning).
  • Of learning: Summative Assignment (16 Q, 100 pts, hybrid auto/teacher-marked), Summative Test (26 Q, 100 pts, 120 min, hybrid).

Lesson sequence

  1. Entry Card → Lesson 4.1 (increasing/decreasing + first derivative test) — the f′ sign chart.
  2. Lesson 4.2 (concavity + second derivative test) — the f″ sign chart → Formative Check A (4.1).
  3. Lesson 4.3 (points of inflection) — where the bending reverses.
  4. Lesson 4.4 (vertical and horizontal asymptotes) — limits as guard rails → Formative Check B (4.2 + 4.3).
  5. Lesson 4.5 (the curve sketching algorithm) — full assembly, polynomial + rational.
  6. Lesson 4.6 (applied curve sketching + optimization connections) — reading real graphs, diminishing returns → Formative Check C (4.4 + 4.5 + 4.6).
  7. Summative Assignment → Summative Test → Discussion → Exit Card.

Materials

Nelson Calculus and Vectors 12 Ch. 4 (PDF pp. ~161–220, verified); Desmos (embedded in each lesson); curated video per lesson; 12 original matplotlib figures embedded in lessons.

Differentiation

Formative checks give instant targeted feedback for self-pacing. Extension: "Thinking" items (e.g. the (x+2)/(x²−4) hole-vs-asymptote distinction, constructing rational functions from feature lists, the diminishing-returns analysis) and sketching from feature lists where the answer is not unique. Support: every lesson's Desmos exploration makes the sign charts visual before the algebra; the six-step algorithm gives a repeatable scaffold; worked examples show every algebraic step.

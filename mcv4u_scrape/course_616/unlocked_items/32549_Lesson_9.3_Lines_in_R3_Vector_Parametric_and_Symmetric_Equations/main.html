Vector, Parametric, and Symmetric Equations of a Line in R3

Nelson Calculus and Vectors 12 §8.3 — the R2 equations grow a third component, and a new parameter-free form appears.

🎯 Learning Goals

By the end of this lesson, you can:

  • Write the vector, parametric, and symmetric equations of a line in R3.
  • Handle zero direction numbers in symmetric form (a constant variable).
  • Decide whether two given line equations describe the same line or different lines.

💡 Minds On

In R3, "slope" loses its meaning — there is no single number like rise-over-run — so Cartesian equations of lines don't exist in three dimensions. But the vector and parametric forms from Lesson 9.1 extend effortlessly: just add a third component. With r0 = (x0, y0, z0) and direction vector m = (a, b, c), the vector equation is still r = r0 + tm, and the parametric equations are x = x0 + ta, y = y0 + tb, z = z0 + tc. Solving each parametric equation for t yields something brand new: the symmetric equations, a parameter-free description of the line.

📖 Learn — step by step

Three forms of a line in R3

All three forms come from the same data: a point P0(x0, y0, z0) and a direction vector m = (a, b, c).

  • Vector: r = (x0, y0, z0) + t(a, b, c), t ∈ R
  • Parametric: x = x0 + ta, y = y0 + tb, z = z0 + tc, t ∈ R
  • Symmetric: (x − x0)/a = (y − y0)/b = (z − z0)/c — valid only when a, b, c ≠ 0

If a direction number is 0, that coordinate never changes along the line, so you write it as a constant instead. For example, direction (1, 0, −1) through (−2, 3, 1) gives (x + 2)/1 = (z − 1)/(−1), y = 3.

Example 1 — Write the vector and parametric equations of the line through P(−2, 3, 5) and Q(−2, 4, −1).

Solution. (Direction vector.) PQ = (−2 − (−2), 4 − 3, −1 − 5) = (0, 1, −6); the scalar multiple (0, −1, 6) is equally valid as a direction vector.
(Vector equation, anchored at P.) r = (−2, 3, 5) + s(0, −1, 6),  s ∈ R.
(Parametric.) x = −2,  y = 3 − s,  z = 5 + 6s,  s ∈ R.
An equally valid form anchored at Q: r = (−2, 4, −1) + t(0, −2, 12) — the direction vector is 2(0, −1, 6), still parallel.
Answer: r = (−2, 3, 5) + s(0, −1, 6); x = −2, y = 3 − s, z = 5 + 6s.

Example 2 — Do the pairs of equations below describe the same line or different lines?
(a) L1: r = (−1, 0, 4) + s(−1, 2, 5);  L2: r = (4, −10, −21) + m(−2, 4, 10)
(b) L3: r = (1, 6, 1) + l(−1, 1, 2);  L4: r = (−3, 10, 12) + k(1/2, −1/2, −1)

Solution. (a) Compare directions. (−2, 4, 10) = 2(−1, 2, 5): parallel. (Check a shared point.) Is (4, −10, −21) on L1? Set (−1, 0, 4) + s(−1, 2, 5) = (4, −10, −21): from x, −1 − s = 4 → s = −5; check y: 0 + 2(−5) = −10 ✓; check z: 4 + 5(−5) = −21 ✓. All three agree — same line.
(b) Compare directions. (1/2, −1/2, −1) = −(1/2)(−1, 1, 2): parallel. (Check a shared point.) Is (−3, 10, 12) on L3? Set (1, 6, 1) + l(−1, 1, 2) = (−3, 10, 12): from x, l = 4; from z, 1 + 2l = 12 → l = 11/2. Inconsistent — different (parallel) lines.
Answer: (a) the same line; (b) different lines.

Example 3 — Write symmetric equations for:
(a) the line through A(−1, 5, 7) and B(3, −4, 8);
(b) the line through P(−2, 3, 1) and Q(4, 3, −5).

Solution. (a) Direction vector. AB = (3 − (−1), −4 − 5, 8 − 7) = (4, −9, 1). Anchored at A:
(x + 1)/4 = (y − 5)/(−9) = (z − 7)/1.
(b) Direction vector. PQ = (6, 0, −6) = 6(1, 0, −1), so use (1, 0, −1). The y-direction number is 0, meaning y is constant at 3 along the whole line. Writing the symmetric form for x and z only:
(x + 2)/1 = (z − 1)/(−1),  y = 3.
Answer: (a) (x+1)/4 = (y−5)/(−9) = (z−7)/1; (b) (x+2)/1 = (z−1)/(−1), y = 3.

Question 1 — Write the vector, parametric, and symmetric equations of the line through A(−1, 2, 4) and B(3, −3, 5).

Direction vector: AB = (4, −5, 1). Vector: r = (−1, 2, 4) + t(4, −5, 1). Parametric: x = −1 + 4t, y = 2 − 5t, z = 4 + t. Symmetric: (x + 1)/4 = (y − 2)/(−5) = (z − 4)/1.

Question 2 — Explain why no symmetric equation is possible for the line through A(−1, 5, −4) and B(2, 5, −4).

Direction vector: AB = (3, 0, 0). Two direction numbers are zero, so the symmetric form would require dividing by zero. The line is actually horizontal: y = 5 and z = −4 everywhere, with only x varying. Parametric: x = −1 + 3t, y = 5, z = −4.

Question 3 — Show that A(6, −2, 15) and B(−15, 5, −27) lie on the line through (0, 0, 3) with direction (−3, 1, −6).

Line: r = (0, 0, 3) + t(−3, 1, −6). For A: (0, 0, 3) + t(−3, 1, −6) = (6, −2, 15) → from x, t = −2; check y: −2 ✓; check z: 3 + (−6)(−2) = 15 ✓. For B: t = 5 from x; check y: 5 ✓; check z: 3 − 30 = −27 ✓. Both lie on the line (t = −2 and t = 5).

Question 4 — Find k so that the direction vectors of the symmetric lines (x − 1)/2 = (y + 3)/k = (z − 2)/1 and (x + 2)/1 = (y − 1)/3 = (z + 4)/(−2) are perpendicular.

Direction vectors: (2, k, 1) and (1, 3, −2). Perpendicular ⇔ dot product 0: 2(1) + 3k + 1(−2) = 0 → 2 + 3k − 2 = 0 → k = 0.

📝 Lesson Summary

Key ideas

  • Vector: r = r0 + tm. Parametric: x = x0 + ta, y = y0 + tb, z = z0 + tc. Symmetric: (x−x0)/a = (y−y0)/b = (z−z0)/c (needs a, b, c ≠ 0).
  • A zero direction number means that coordinate is constant — write it as an equation like y = 3.
  • Same line test: parallel direction vectors and a shared point (one consistent parameter value in all coordinates).

Need to know

  • There are no Cartesian (scalar) equations of lines in R3 — slope has no meaning in 3D.
  • Choose integer direction vectors with common factors removed to keep work tidy.

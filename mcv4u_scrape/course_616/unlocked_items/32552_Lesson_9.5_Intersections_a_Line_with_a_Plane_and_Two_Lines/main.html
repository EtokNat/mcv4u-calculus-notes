LESSON 9.5

Intersections: a Line with a Plane, and Two Lines

Nelson Calculus and Vectors 12 §§9.1–9.2 — substitution turns geometry into algebra: solving systems reveals the picture.

🎯 Learning Goals

By the end of this lesson, you can:

  • Find the intersection point of a line and a plane (or recognize parallel / line-on-plane cases).
  • Classify two lines in R3 as parallel, intersecting, or skew, and find the intersection point when it exists.
  • Solve 2×2 and 3×3 systems of equations by elimination using the three elementary operations.

💡 Minds On

A line and a plane in R3 have exactly three possible relationships: they meet at one point, they never meet (the line is parallel to the plane), or the line lies entirely on the plane (infinitely many intersection points). The trick is substitution: write the line in parametric form, plug its x, y, z into the plane's Cartesian equation, and solve for the parameter. What the parameter equation says tells you which case you're in: a single value → one point; an impossible equation like 0 = −19 → parallel; an identity like 0 = 0 → the line is on the plane. Two lines in R3 add a fourth possibility — skew lines, which are neither parallel nor intersecting.

📖 Learn — step by step

Line meets plane: substitute and solve

Write the line parametrically: x = x0 + ta, y = y0 + tb, z = z0 + tc. Substitute into the plane's Cartesian equation Ax + By + Cz + D = 0 and solve for t:

  • One value of t → the line pierces the plane at a single point (substitute t back to find it).
  • Impossible equation (e.g. 0 = −19) → no solution: the line is parallel to the plane. Quick check: direction vector · normal = 0.
  • Identity (e.g. 0 = 0) → every t works: the line lies on the plane.

Two lines in R3: parallel, intersecting, or skew

Compare the direction vectors first: parallel directions mean the lines are parallel (check a point from one on the other to separate "same line" from "parallel distinct"). Otherwise, equate coordinates with different parameters (t for line 1, s for line 2), solve two of the three equations, and test the solution in the third: if it checks out, the lines intersect at one point; if not, they are skew.

Systems of equations by elimination

Intersections are systems of equations in disguise. The three elementary operations produce equivalent systems: (1) multiply an equation by a nonzero constant; (2) add a multiple of one equation to another; (3) interchange two equations. For a 3×3 system, eliminate one variable to get a 2×2 system, then eliminate again to get one equation in one unknown — then back-substitute.

Example 1 — Find the intersection of the line (x − 1)/3 = (y + 2)/(−2) = z − 5 with the plane x + 2y − 3z = −1.

Solution. (Parametric form of the line.) Let the common value be t: x = 1 + 3t, y = −2 − 2t, z = 5 + t.
(Substitute into the plane.) (1 + 3t) + 2(−2 − 2t) − 3(5 + t) = −1 → 1 + 3t − 4 − 4t − 15 − 3t = −1 → −18 − 4t = −1 → −4t = 17 → t = −17/4.
(Point.) x = 1 + 3(−17/4) = 1 − 51/4 = −47/4; y = −2 − 2(−17/4) = −2 + 17/2 = 13/2; z = 5 − 17/4 = 3/4.
Answer: (−47/4, 13/2, 3/4).

Example 2 — Describe the intersection of:
(a) the line (x − 1)/3 = (y + 2)/1 = (z − 5)/2 with the plane x + 2y + 3z = 1;
(b) the line x = −2 + t, y = 5 + 2t, z = 1 + t with the plane x − 2y + 2z = 0.

Solution. (a) Substitute. x = 1 + 3t, y = −2 + t, z = 5 + 2t into x + 2y + 3z = 1:
(1 + 3t) + 2(−2 + t) + 3(5 + 2t) = 1 → 1 + 3t − 4 + 2t + 15 + 6t = 1 → 12 + 11t = 1 → 11t = −11 → t = −1.
Point: x = 1 − 3 = −2; y = −2 − 1 = −3; z = 5 − 2 = 3. One intersection: (−2, −3, 3).
(b) Substitute. (−2 + t) − 2(5 + 2t) + 2(1 + t) = 0 → −2 + t − 10 − 4t + 2 + 2t = 0 → −10 − t = 0 → t = −10.
Point: x = −2 − 10 = −12; y = 5 + 2(−10) = −15; z = 1 − 10 = −9. One intersection: (−12, −15, −9).
(Reading the algebra.) In general: if substitution reduces to 0 = 0 (every coefficient of t cancels and the constants match), the line lies on the plane — infinitely many intersections. If it reduces to something impossible like 0 = 5, the line is parallel to the plane (and the quick check d · n = 0 confirms it).
Answer: (a) single point (−2, −3, 3); (b) single point (−12, −15, −9). The 0 = 0 vs 0 = nonzero test separates "line on plane" from "parallel".

Example 3 — Determine whether L1: x = 1 − 2t, y = 5 + t, z = 2 + 3t and L2: (x − 2)/3 = (y − 1)/(−2) = (z − 1)/2 intersect, are parallel, or are skew.

Solution. (Directions.) m1 = (−2, 1, 3), m2 = (3, −2, 2): not scalar multiples → not parallel.
(Equate with different parameters.) L2 in parametric form: x = 2 + 3s, y = 1 − 2s, z = 1 + 2s. Set equal to L1:
1 − 2t = 2 + 3s …(i);  5 + t = 1 − 2s …(ii);  2 + 3t = 1 + 2s …(iii).
(Solve (i) and (ii).) From (ii): t = −4 − 2s. Into (i): 1 − 2(−4 − 2s) = 2 + 3s → 1 + 8 + 4s = 2 + 3s → s = −7, t = −4 − 2(−7) = 10.
(Test in (iii).) LHS: 2 + 3(10) = 32; RHS: 1 + 2(−7) = −13. 32 ≠ −13 — the third equation fails → skew lines.
Answer: the lines are skew (not parallel, no common point).

Example 4 — Solve the system x + y + z = 3, 2x − y + z = 0, x − 2y − z = −4 by elimination.

Solution. (Eliminate z: add equations strategically.) Label (1), (2), (3).
(1) + (3): (x + y + z) + (x − 2y − z) = 3 + (−4) → 2x − y = −1 …(4).
(2) + (3): (2x − y + z) + (x − 2y − z) = 0 + (−4) → 3x − 3y = −4 …(5).
(2×2 system.) From (4): y = 2x + 1. Into (5): 3x − 3(2x + 1) = −4 → 3x − 6x − 3 = −4 → −3x = −1 → x = 1/3. Then y = 2(1/3) + 1 = 5/3. From (1): z = 3 − 1/3 − 5/3 = 3 − 2 = 1.
(Verify in (2).) 2(1/3) − 5/3 + 1 = 2/3 − 5/3 + 1 = 0 ✓.
Answer: (1/3, 5/3, 1).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercises 9.1–9.2.

Question 1 — Find the intersection point of the line x = 2 + t, y = 1 − t, z = 3 + 2t with the plane 2x − y + z = 9.

Substitute: 2(2 + t) − (1 − t) + (3 + 2t) = 9 → 4 + 2t − 1 + t + 3 + 2t = 9 → 6 + 5t = 9 → t = 3/5. Point: x = 2 + 3/5 = 13/5, y = 1 − 3/5 = 2/5, z = 3 + 6/5 = 21/5. Answer: (13/5, 2/5, 21/5).

Question 2 — Show that the line r = (1, 0, 2) + t(2, 1, −1) is parallel to the plane 2x + y + 3z = 5, and confirm they never meet.

Direction d = (2, 1, −1), normal n = (2, 1, 3): d · n = 4 + 1 − 3 = 2 ≠ 0 — so actually NOT parallel! Substitute: x = 1 + 2t, y = t, z = 2 − t → 2(1 + 2t) + t + 3(2 − t) = 5 → 2 + 4t + t + 6 − 3t = 5 → 8 + 2t = 5 → t = −3/2. The line pierces the plane at (−2, −3/2, 7/2). (Moral: always check d · n before assuming.)

Question 3 — Classify the system 2x + 3y = 5, 4x + 6y = 11. What does the graph show?

Multiply the first equation by 2: 4x + 6y = 10. Subtracting from the second gives 0 = 1 — impossible. No solution: the lines are parallel and distinct (same normal (2, 3), different constants).

Question 4 — Explain why the parameters must satisfy all three coordinate equations for two lines to intersect.

An intersection point must lie on both lines simultaneously — its x, y, and z coordinates must each match. Solving only two of the three equations finds parameter values that agree in two coordinates; if the third coordinate disagrees, the "points" are actually two different points (one on each line) that merely share two coordinates — the hallmark of skew lines.

📝 Lesson Summary

Key ideas

  • Line ∩ plane: substitute the parametric line into the plane equation. One t → one point; 0 = nonzero → parallel; 0 = 0 → line on plane.
  • Two lines: parallel directions → parallel (test a point); otherwise equate coordinates with different parameters — a consistent solution in all three coordinates means intersecting, otherwise skew.
  • Systems: three elementary operations (scale, add multiples, swap) preserve solutions; reduce 3×3 → 2×2 → 1×1, then back-substitute.

Need to know

  • Use different parameters (t and s) for the two lines — reusing one letter causes false solutions.

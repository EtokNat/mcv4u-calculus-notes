Vector and Parametric Equations of a Line in R2

Nelson Calculus and Vectors 12 §8.1 — one anchor point plus one direction vector generates every point on a line.

🎯 Learning Goals

By the end of this lesson, you can:

  • Write the vector equation r = r0 + tm of a line in R2 from a point and a direction vector.
  • Write the matching parametric equations x = x0 + ta, y = y0 + tb.
  • Test whether a point lies on a line, find intercepts, and recognize equivalent forms of the same line.

💡 Minds On

A line in R2 is completely pinned down by just two pieces of information: one point it passes through and one direction vector m = (a, b) — a nonzero vector pointing along the line. The components of m are called its direction numbers. Because stretching a direction vector (multiplying it by any nonzero scalar) doesn't change the direction it points, every nonzero scalar multiple of a direction vector is also a valid direction vector — but the zero vector is never allowed, since it would give the line no direction at all. Game programmers (the chapter's Career Link) use exactly this idea: one anchor point plus a direction describes the path of a bouncing ball.

📖 Learn — step by step

The vector equation of a line

Let P0(x0, y0) be a known point on the line with position vector r0, and let P(x, y) be any general point on the line with position vector r. The vector from P0 to P points along the line, so it must be a scalar multiple of the direction vector m: P0P = tm. Adding vectors tip-to-tail (the triangle law) gives OP = OP0 + P0P, that is, the vector equation

r = r0 + tm,  t ∈ R

Every value of the parameter t produces a different point of the line; as t sweeps over all real numbers, r sweeps over the entire line.

The parametric equations of a line

Writing r = (x, y), r0 = (x0, y0), and m = (a, b) component-wise gives the parametric equations

x = x0 + ta,  y = y0 + tb,  t ∈ R

It is often convenient to simplify a direction vector first — dividing out common factors or clearing fractions keeps the arithmetic clean, since any nonzero scalar multiple works.

Example 1 — Write the vector and parametric equations of the line through A(1, 4) with direction vector m = (−3, 3). Use the equations to decide whether Q(−21, 23) and R(−29, 34) lie on the line.

Solution. With r0 = (1, 4) and m = (−3, 3), the vector equation is
r = (1, 4) + t(−3, 3),  t ∈ R.
Component-wise, the parametric equations are
x = 1 − 3t,  y = 4 + 3t,  t ∈ R.
(Simplify the direction vector.) Since (−3, 3) = −3(1, −1) = 3(−1, 1), a neater equivalent form uses m = (−1, 1):
r = (1, 4) + s(−1, 1),  s ∈ R,   i.e.  x = 1 − s,  y = 4 + s.
(Test Q(−21, 23).) From x = 1 − s = −21 we get s = 22, but then y = 4 + 22 = 26 ≠ 23. The two equations give inconsistent parameter values, so Q is not on the line.
(Test R(−29, 34).) From x = 1 − s = −29 we get s = 30, and y = 4 + 30 = 34 ✓. Both equations agree (s = 30), so R is on the line.
Answer: r = (1, 4) + t(−3, 3); x = 1 − 3t, y = 4 + 3t. R is on the line (t-equivalent s = 30); Q is not.

Example 2 — Write vector and parametric equations of the line through E(−1, 5) and F(6, 11), and find its x-intercept.

Solution. (Direction vector.) EF = (6 − (−1), 11 − 5) = (7, 6).
With r0 = (−1, 5):
r = (−1, 5) + s(7, 6),  s ∈ R;   x = −1 + 7s,  y = 5 + 6s.
(x-intercept: set y = 0.) 5 + 6s = 0 → s = −5/6. Then x = −1 + 7(−5/6) = −1 − 35/6 = −41/6.
Answer: r = (−1, 5) + s(7, 6); x = −1 + 7s, y = 5 + 6s. The x-intercept is (−41/6, 0).

Example 3 — Write a vector equation of the line through P(6, 5) that is perpendicular to the line r = (4, 1) + s(−3, 2).

Solution. (Find a perpendicular direction.) The given line has direction (−3, 2). A vector (a, b) perpendicular to it satisfies (−3, 2)·(a, b) = 0, i.e. −3a + 2b = 0. Choosing a = 2 gives b = 3, so (2, 3) is a perpendicular direction vector.
(Anchor at P.) r = (6, 5) + t(2, 3),  t ∈ R.
Answer: r = (6, 5) + t(2, 3).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 8.1.

Question 1 — Write a vector equation and the parametric equations of the line through A(2, 1) and B(−3, 5).

Direction vector: AB = (−3 − 2, 5 − 1) = (−5, 4). Vector equation: r = (2, 1) + t(−5, 4), t ∈ R. Parametric: x = 2 − 5t, y = 1 + 4t.

Question 2 — Does P(−14, 15) lie on the line x = 1 + 3t, y = 5 − 2t?

From x: 1 + 3t = −14 → t = −5. Check y: 5 − 2(−5) = 15 ✓. Both equations agree, so yes, P is on the line (t = −5).

Question 3 - Explain why (-2, -1), (2, 1), and (7, 7/2) are all acceptable direction vectors for the line r = (12, 34) + s(2, 1).

The given line has direction vector (2, 1). Any nonzero scalar multiple of a direction vector is also a direction vector for the same line: (-2, -1) = -1(2, 1) and (7, 7/2) = (7/2)(2, 1), so each points along the same line.
Question 4 — A student "simplifies" r = (1/3, 1/7) + p(−2, 3) by multiplying the point (1/3, 1/7) by 21 to get r = (7, 3) + p(−2, 3). Explain the error.

Multiplying the anchor point by 21 changes the point itself — (7, 3) is not the same point as (1/3, 1/7), and it is not on the original line (check: (1/3, 1/7) + p(−2, 3) = (7, 3) would need p = −10/3 from the x-coordinate but p = 20/21 from the y-coordinate). Only the direction vector may be scaled by a nonzero constant; the anchor point must stay put.

📝 Lesson Summary

Key ideas

  • A line in R2 needs one point (position vector r0) and one nonzero direction vector m = (a, b).
  • Vector equation: r = r0 + tm, t ∈ R. Parametric equations: x = x0 + ta, y = y0 + tb.
  • Any nonzero scalar multiple of m is also a direction vector; the zero vector is never allowed.
  • To test a point: solve for the parameter in both parametric equations — consistent values mean the point is on the line.

Need to know

  • Simplify direction vectors (integer components, common factors removed) before doing arithmetic.
  • Different-looking equations can describe the same line — check shared points and parallel directions.

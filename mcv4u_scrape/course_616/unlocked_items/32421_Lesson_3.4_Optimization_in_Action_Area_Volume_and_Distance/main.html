💡 Minds On

We frequently encounter situations in which we are asked to do the best we can — minimize cost, maximize area. Such a procedure is called optimization: realizing the best possible outcome, subject to a set of restrictions. Because of the restrictions, the domain of the function is usually restricted — and the maximum or minimum might occur at the ends of the restricted domain.

📖 Learn — step by step

Algorithm for Solving Optimization Problems.
  1. Understand the problem; identify what varies. Write the quantity to optimize as a function of one variable.
  2. Whenever possible, draw a diagram, labelling the given and required quantities.
  3. Determine the domain of the function from the given information.
  4. Apply the extreme-value algorithm to find the absolute maximum or minimum in the domain.
  5. Use the result to answer the original problem.

Example 1 — A farmer has 800 m of fencing and wishes to enclose a rectangular field. One side of the field is against a country road that is already fenced, so the farmer needs to fence only the remaining three sides. The farmer wants the maximum possible area using all the fencing. What dimensions achieve this?

Solution. Let the width of the enclosed area be x metres. Then the length is (800 − 2x) m, and the area is
A(x) = x(800 − 2x) = 800x − 2x².
The domain is 0 < x < 400, since the fencing totals 800 m. To find extreme values, A′(x) = 800 − 4x. Setting A′(x) = 0 gives x = 200.
The minimum and maximum can occur at x = 200 or at the ends x = 0 and x = 400:
A(0) = 0;   A(200) = 200(800 − 400) = 80 000;   A(400) = 400(800 − 800) = 0.
Sometimes the ends of the domain produce impossible results — here x = 200 gives the maximum, while the ends give zero-area "rectangles" that are not possible dimensions.
The maximum area is 80 000 m², in a field 200 m by 400 m.

Example 2 — A piece of sheet metal, 60 cm by 30 cm, is to be used to make a rectangular box with an open top. Determine the dimensions that give the box with the largest volume.

Solution. Cut corner squares of side x cm and fold up the sides. Then height = x, length = 60 − 2x, width = 30 − 2x. Since all dimensions are positive, 0 < x < 15.
V(x) = x(60 − 2x)(30 − 2x) = 4x³ − 180x² + 1800x.
For extreme values, set V′(x) = 0: V′(x) = 12x² − 360x + 1800 = 12(x² − 30x + 150). Solving x² − 30x + 150 = 0 by the quadratic formula:
x = [30 ± √300]/2 = 15 ± 5√3, so x ≈ 23.7 or x ≈ 6.3.
Since 0 < x < 15, only x = 15 − 5√3 ≈ 6.3 is in the interval. V(6.3) = 4(6.3)³ − 180(6.3)² + 1800(6.3) ≈ 5196.
The endpoints need no test — x = 0 or x = 15 makes no box at all.
Maximum volume comes from corner squares of side 6.3 cm: the box is about 47.4 cm × 17.4 cm × 6.3 cm.

Example 3 — Ian and Ada are training for a marathon. Ian's house is 20 km north of Ada's house. At 9:00 a.m. one Saturday, Ian leaves home jogging south at 8 km/h while Ada leaves home jogging east at 6 km/h. When are Ian and Ada closest together, if they both run for 2.5 h?

Solution. After t hours, Ian has jogged IJ = 8t km south, so JA = (20 − 8t) km; Ada has jogged AB = 6t km east. Their separation is s = JB, with
s(t) = √(JA² + AB²) = √((20 − 8t)² + (6t)²) = √(100t² − 320t + 400) = (100t² − 320t + 400)^(1/2).
The domain is 0 ≤ t ≤ 2.5. Differentiating,
s′(t) = (1/2)(100t² − 320t + 400)^(−1/2)(200t − 320) = (100t − 160)/√(100t² − 320t + 400).
Setting s′(t) = 0 gives 100t − 160 = 0, so t = 1.6. Applying the extreme-value algorithm:
s(0) = √400 = 20;   s(1.6) = √(100(1.6)² − 320(1.6) + 400) = 12;   s(2.5) = √225 = 15.
The minimum separation is 12 km, at t = 1.6 h — that is, at 10:36 a.m.

Question 1 — A 100 cm wire is bent into a rectangle. What dimensions give the maximum area?

Let one side be x: A = x(50 − x); A′ = 50 − 2x = 0 → x = 25. A 25 cm × 25 cm square (625 cm²).

Question 2 — A rectangle has perimeter 440 cm. What dimensions maximize its area?

A = x(220 − x); A′ = 220 − 2x = 0 → x = 110. A 110 cm × 110 cm square.

Question 3 — A rectangle has area 64 m². What dimensions give the smallest perimeter?

P = 2x + 128/x; P′ = 2 − 128/x² = 0 → x = 8. An 8 m × 8 m square (perimeter 32 m).

Question 4 — A farmer has 600 m of fence beside a river (3 sides fenced). What dimensions maximize the area?

A = x(600 − 2x); A′ = 600 − 4x = 0 → x = 150. 150 m × 300 m (45 000 m²).

📝 Lesson Summary

Key ideas

  • In an optimization problem, determine the maximum or minimum value of a quantity.
  • Solve it with a mathematical model built from the problem's information — the numerical solution is the extreme value of the model.

Need to know — the algorithm

  • One-variable function → labelled diagram → domain from the constraints → extreme-value algorithm → answer the original question.
  • Endpoints can hold the optimum — but check they are physically possible.

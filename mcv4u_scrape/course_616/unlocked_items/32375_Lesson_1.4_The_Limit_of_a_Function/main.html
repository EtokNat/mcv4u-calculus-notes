The Limit of a Function

Nelson Calculus and Vectors 12 §1.4 — the precise idea behind every "limh→0" you have written so far.

🎯 Learning Goals

By the end of this lesson, you can:

  • State the intuitive meaning of limx→a f(x) = L.
  • Estimate limits from graphs and tables of values, including one-sided limits.
  • Decide whether a limit exists — and explain why the value f(a) does not settle the question.

💡 Minds On

The notation limx→a f(x) = L is read "the limit of f(x) as x approaches a equals L". It means the value of f(x) can be made arbitrarily close to L by choosing x sufficiently close to a (but not equal to a). And here is the key test you will use all unit: limx→a f(x) exists if and only if the limiting value from the left equals the limiting value from the right. (Note: this is an intuitive explanation. A more precise definition using inequalities belongs to advanced work and is not needed here.)

📖 Learn — step by step

Example 1 — Determine limx→1 (x² − 1)/(x − 1) by graphing.

Solution. On a graphing calculator, display f(x) = (x² − 1)/(x − 1), x ≠ 1. The graph looks like the line f(x) = x + 1 — but it is really that line with the point (1, 2) deleted. Using TRACE near x = 1: at X = 0.9, Y = 1.9; at X = 1, Y has no value; at X = 1.1, Y = 2.1.
We estimate limx→1 f(x). As x approaches 1 from the left (written x → 1⁻), f(x) approaches 2 from below. As x approaches 1 from the right (x → 1⁺), f(x) approaches 2 from above.
We say the limit at x = 1 exists only if the value approached from the left is the same as the value approached from the right. Here both are 2, so limx→1 (x² − 1)/(x − 1) = 2 — even though f(1) itself is undefined.

Example 2 — Determine limx→1 (x² − 1)/(x − 1) using a table.

Solution. Choose sequences for x → 1⁻ and x → 1⁺:

x → 1⁻00.50.90.990.999
f(x)11.51.91.991.999
x → 1⁺21.51.11.011.001
f(x)32.52.12.012.001

f(x) approaches 2 from below on the left and from above on the right — the same pattern as the graph in Example 1, confirming limx→1 (x² − 1)/(x − 1) = 2.

Example 3 — Sketch the piecewise function f(x) = { x − 1, if x < 1; 1, if x = 1; 2 + √(x − 1), if x > 1 }. Determine limx→1 f(x).

Solution. The graph consists of the line y = x − 1 for x < 1, the single point (1, 1), and the square-root branch y = 2 + √(x − 1) for x > 1.
As x → 1⁻, f(x) approaches 0 from below: limx→1⁻ f(x) = limx→1⁻ (x − 1) = 0.
As x → 1⁺, f(x) approaches 2 from above: limx→1⁺ f(x) = limx→1⁺ (2 + √(x − 1)) = 2.
Since the left-hand and right-hand limits are not the same, f(x) does not approach a single value as x → 1. We say "the limit of f(x) as x → 1 does not exist" — and this stays true even though f(1) = 1 is defined. The value of the function at the point never decides a limit; only the behaviour near the point matters.

Limits and Their Existence. We say that the number L is the limit of y = f(x) as x approaches a, written limx→a f(x) = L, if limx→a⁻ f(x) = L = limx→a⁺ f(x). Otherwise, limx→a f(x) does not exist.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 1.4.

Question 1 — Write a concise description of: (a) a right-sided limit, (b) a left-sided limit, (c) a (two-sided) limit.

(a) The value f(x) approaches as x nears a from values greater than a. (b) From values less than a. (c) The common value both one-sided limits approach — which exists only when they agree.

Question 2 — Let f(x) = 1 when x ≠ 4 and f(4) = −1. Determine limx→4 f(x).

Near x = 4 (but not at x = 4), f(x) is constantly 1, so the limit is 1 — the odd value at x = 4 itself is irrelevant.

Question 3 — Evaluate limx→−1 (9 − x)².

As x → −1, (9 − x) → 10, so the limit is 100.

Question 4 — If limx→a⁻ f(x) = 3 and limx→a⁺ f(x) = 3, what is limx→a f(x)? What if the right-hand limit were 5 instead?

3 — the two sides agree. If the right-hand limit were 5, the two-sided limit would not exist.

📝 Lesson Summary

Key idea

  • limx→a f(x) = L means f(x) approaches L as x approaches a from both the left and the right side.

Need to know

  • limx→a f(x) may exist even if f(a) is not defined (Example 1).
  • limx→a f(x) can equal f(a) — then the graph passes through the point (a, f(a)).
  • If limx→a⁻ f(x) = L and limx→a⁺ f(x) = L, then L is the limit as x → a.

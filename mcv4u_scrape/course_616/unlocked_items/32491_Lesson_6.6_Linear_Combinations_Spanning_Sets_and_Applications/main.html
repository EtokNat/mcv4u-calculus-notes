🎯 Learning Goals

By the end of this lesson, you can:

  • Write a vector as a linear combination au + bv by solving for the scalars.
  • Decide whether a set of vectors spans R², R³, or a plane — and explain why collinear sets fail.
  • Test whether a vector lies in a plane determined by two vectors, and apply combinations to forces and motion.

💡 Minds On

With just the two arrows (1, 0) and (0, 1), you can reach every point of the plane: (4, 23) is just 4 of the first plus 23 of the second. But swap in (2, 3) and (4, 6), and suddenly whole regions become unreachable. Today you learn which small sets of vectors can build everything — and which can't.

📖 Learn — step by step

Key term — Linear combination: for vectors u, v, any vector of the form au + bv (a, b real scalars) — scale each vector, then add. Geometrically, it's the diagonal of the parallelogram on au and bv.
  • Finding the combination. Set au + bv equal to the target vector, match components, and solve the resulting system. Two equations, two unknowns — elimination does it.
  • Spanning sets. A set of vectors spans a space if every vector there can be written as a combination of them. {i, j} spans R²; {i, j, k} spans R³ — the standard bases.
  • The two-vector rule. Any pair of nonzero, noncollinear vectors spans R². Collinear pairs fail: multiples of (2, 3) can only ever produce arrows along that one line — e.g. (3, 4) is unreachable from {(2, 3), (4, 6)}.
  • Planes in R³. Two nonzero, noncollinear vectors span a plane in R³; every ma + nb lands on it, and points/vectors there are coplanar. To test whether c lies in a and b's plane: solve two of the three component equations for m, n, then check consistency in the third — consistent means coplanar.
  • Why it matters. Real combined effects are linear combinations: a skater's jump is d + e (setup plus push-off), and landing safely adds the braking force f. Each piece's direction decides the result.

Example 1 — Show that (4, 23) can be written as a linear combination of (−1, 4) and (2, 5).

Solution. Seek a, b with a(−1, 4) + b(2, 5) = (4, 23). Matching components:
−a + 2b = 4   (1)
4a + 5b = 23   (2)
Multiply (1) by 4: −4a + 8b = 16. Add (2): 13b = 39 → b = 3; then a = 2.
Check: 2(−1, 4) + 3(2, 5) = (−2 + 6, 8 + 15) = (4, 23). ✓

Example 2 — Show that {(2, 1), (−3, −1)} is a spanning set for R², and write (−3, 7) as a combination of them.

Solution. For a general (x, y): a(2, 1) + b(−3, −1) = (x, y) gives 2a − 3b = x and a − b = y. Solving gives b = 2y − x and a = 3y − x — a formula that works for any (x, y), so the set spans R².
For (−3, 7): a = 3(7) − (−3) = 24, b = 2(7) − (−3) = 17.
Verify: 24(2, 1) + 17(−3, −1) = (48 − 51, 24 − 17) = (−3, 7). ✓

Example 3 — Do the vectors a = (−1, −2, 1) and b = (3, −1, 1) span a plane containing c = (−9, −4, 1)? Explain.

Solution. Seek m, n with m(−1, −2, 1) + n(3, −1, 1) = (−9, −4, 1):
−m + 3n = −9   (1);   −2m − n = −4   (2);   m + n = 1   (3).
Add (1) and (3): 4n = −8 → n = −2; then m = 3.
Check in (2): −2(3) − (−2) = −6 + 2 = −4 ✓ — consistent.
So c = 3a − 2b: it does lie in the plane spanned by a and b.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 6.8.

Question 1 — Write (−10, −34) as a linear combination of (−1, 3) and (1, 5).

a(−1, 3) + b(1, 5) = (−10, −34): −a + b = −10, 3a + 5b = −34 → b = a − 10 → 3a + 5a − 50 = −34 → a = 2, b = −8. Check: 2(−1, 3) − 8(1, 5) = (−2 − 8, 6 − 40) = (−10, −34). ✓

Question 2 — A student claims {(1, 0), (−1, 0)} spans R² because 2(1, 0) + 4(−1, 0) = (−2, 0). What's wrong?

Both vectors are multiples of (1, 0) — they're collinear. Every combination stays on the x-axis; e.g. (0, 1) can never be built. One example of a combination is not a spanning proof.

Question 3 — Describe the set of vectors spanned by (0, 1). Why does (0, −1) span the same set?

All scalar multiples of (0, 1): the entire y-axis. (0, −1) = −1·(0, 1), so its multiples are the same line — collinear vectors span the same line.

Question 4 — The set {(1, 0, 0), (0, 1, 0)} spans a set in R³. Describe it, and explain why (3, 5, 8) is not in it.

Combinations a(1,0,0) + b(0,1,0) = (a, b, 0): the xy-plane (z = 0). (3, 5, 8) has z = 8 ≠ 0, so no combination can reach it.

📝 Lesson Summary

Key ideas

  • Linear combination au + bv: scale, then add (parallelogram diagonal); find the scalars by solving the component system.
  • Spanning: two nonzero noncollinear vectors span R²; {i, j, k} spans R³; two such vectors span a plane in R³.
  • Coplanarity test: solve two component equations, verify in the third — consistency means "in the plane."

Need to know

  • Collinear (or zero) vectors can never complete a spanning set — you need genuinely different directions.

The Derivative Function

🎯 Learning Goals

By the end of this lesson, you can:

  • Find the derivative function f′(x) from first principles.
  • Find the equation of a tangent and a normal to a curve.
  • Identify where a function is not differentiable (cusp, vertical tangent, discontinuity) and use the notations f′(x), y′, dy/dx.

💡 Minds On

In Unit 1 you kept meeting the limit limh→0 [f(a + h) − f(a)]/h. It has two interpretations: the slope of the tangent to y = f(x) at (a, f(a)), and the instantaneous rate of change of y = f(x) with respect to x at x = a. Since this limit is central to calculus, it is given a name and a concise notation: it is called the derivative of f(x) at x = a, denoted f′(a) and read "f prime of a".

📖 Learn — step by step

The Derivative at a Point. The derivative of f at the number a is given by f′(a) = limh→0 [f(a + h) − f(a)]/h, provided this limit exists. An alternative form is f′(a) = limx→a [f(x) − f(a)]/(x − a).

Example 1 — Determine the derivative of f(x) = x² at x = −3.

Solution. Using the definition, the derivative at x = −3 is
f′(−3) = limh→0 [f(−3 + h) − f(−3)]/h
= limh→0 [(−3 + h)² − (−3)²]/h   (Expand)
= limh→0 [9 − 6h + h² − 9]/h   (Simplify and factor)
= limh→0 h(−6 + h)/h
= limh→0 (−6 + h)
= −6.
Therefore, the derivative of f(x) = x² at x = −3 is −6.

Example 2 — a. Determine the derivative of f(x) = x² at an arbitrary value of x. b. Determine the slopes of the tangents to the parabola y = x² at x = −2, 0, and 1.

Solution.
a. Using the definition, f′(x) = limh→0 [f(x + h) − f(x)]/h
= limh→0 [(x + h)² − x²]/h   (Expand)
= limh→0 [x² + 2xh + h² − x²]/h   (Simplify and factor)
= limh→0 h(2x + h)/h
= limh→0 (2x + h)
= 2x.
The derivative of f(x) = x² at an arbitrary value of x is f′(x) = 2x.
b. Substitute into f′(x) = 2x: f′(−2) = −4, f′(0) = 0, f′(1) = 2. The slopes are −4, 0, and 2, respectively.

Notice that the graph of the derivative function of the quadratic (degree two) is a linear function (degree one) — differentiating drops the degree by one. The same investigation with x³, x⁴, x⁵ suggests a pattern: the derivative of xⁿ is nxⁿ⁻¹. You will prove this in Lesson 2.2.

The Derivative Function. The derivative of f(x) with respect to x is the function f′(x), where f′(x) = limh→0 [f(x + h) − f(x)]/h, provided this limit exists. Using this limit to find a derivative is called differentiating from first principles. Velocity is the derivative of position: v(t) = s′(t) = limh→0 [s(t + h) − s(t)]/h.

Example 3 — Determine the derivative f′(t) of f(t) = √t, t ≥ 0.

Solution. Using the definition, f′(t) = limh→0 [f(t + h) − f(t)]/h
= limh→0 [√(t + h) − √t]/h
= limh→0 [√(t + h) − √t]/h × [√(t + h) + √t]/[√(t + h) + √t]   (Rationalize the numerator)
= limh→0 [(t + h) − t]/[h(√(t + h) + √t)]
= limh→0 h/[h(√(t + h) + √t)]
= limh→0 1/[√(t + h) + √t]
= 1/(2√t), for t > 0.
Note that f(t) = √t is defined for all t ≥ 0, whereas its derivative f′(t) = 1/(2√t) is defined only for t > 0 — a function need not have a derivative throughout its entire domain.

Example 4 — Determine an equation of the tangent to the graph of f(x) = 1/x at the point where x = 2.

Solution. When x = 2, y = 1/2, so the point is (2, 1/2). First find f′(x):
f′(x) = limh→0 [f(x + h) − f(x)]/h = limh→0 [1/(x + h) − 1/x]/h
= limh→0 [x/(x(x + h)) − (x + h)/(x(x + h))]/h   (Simplify the fraction)
= limh→0 [x − (x + h)]/[h(x + h)x]
= limh→0 −1/[(x + h)x]
= −1/x².
The slope of the tangent at x = 2 is m = f′(2) = −1/4. The equation is y − 1/2 = −1/4(x − 2), or in standard form, x + 4y − 4 = 0.

Example 5 — Determine an equation of the line perpendicular to the tangent in Example 4, through the point of tangency.

Solution. The tangent slope at x = 2 is f′(2) = −1/4, and the point of tangency is (2, 1/2). The perpendicular line has slope 4, the negative reciprocal of −1/4. Its equation is y − 1/2 = 4(x − 2), or 8x − 2y − 15 = 0.

The Normal. The normal to the graph of f at point P is the line perpendicular to the tangent at P.

Example 6 — Show that f(x) = |x| is not differentiable at x = 0.

Solution. The graph has a "corner" at (0, 0): the slope for x < 0 is −1, while the slope for x > 0 is +1, so no unique tangent can be drawn. Using the definition:
f′(0) = limh→0 [f(0 + h) − f(0)]/h = limh→0 |h|/h.
Since |h| = h when h > 0 and |h| = −h when h < 0:
limh→0⁻ |h|/h = limh→0⁻ (−h)/h = −1;   limh→0⁺ |h|/h = limh→0⁺ h/h = 1.
The one-sided limits disagree, so the derivative does not exist at x = 0.

Key consequence. A function can be continuous at a point yet not differentiable there. However, if a function is differentiable at a point, then it is also continuous at that point.

Other notation for derivatives

If y = f(x), the symbols y′ and dy/dx are also used for the derivative. The dy/dx notation was developed by Leibniz and is read "dee y by dee x". It reminds us how the derivative is obtained — as the limit of a difference quotient: dy/dx = limΔx→0 Δy/Δx. We can also write d/dx(x²) = 2x, read "the derivative of x² with respect to x is 2x". Important: dy/dx is not a fraction.

📝 Lesson Summary

Key ideas

  • The derivative of f at (a, f(a)) is f′(a) = limh→0 [f(a + h) − f(a)]/h, or f′(a) = limx→a [f(x) − f(a)]/(x − a).
  • A function is differentiable at a if f′(a) exists; differentiable on an interval if differentiable at every number in it.
  • The derivative function is f′(x) = limh→0 [f(x + h) − f(x)]/h.

Need to know

  • f′(a) is the slope of the tangent at (a, f(a)), or the instantaneous rate of change of f(x) w.r.t. x at x = a.
  • Other notations: f′(x), y′, dy/dx (dy/dx is not a fraction).
  • The normal at P is perpendicular to the tangent at P.

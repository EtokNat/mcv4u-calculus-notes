LESSON 9.2

The Cartesian Equation of a Line in R2

Nelson Calculus and Vectors 12 §8.2 — one equation with no parameter: Ax + By + C = 0, where (A, B) is a normal vector.

🎯 Learning Goals

By the end of this lesson, you can:

  • Write the Cartesian equation Ax + By + C = 0 of a line from a point and a normal vector (or two points).
  • Convert between vector, parametric, and Cartesian forms of a line in R2.
  • Use normals to decide whether lines are parallel or perpendicular, and find the angle between two lines.

💡 Minds On

Vector and parametric equations describe a line by generating its points one parameter value at a time. The Cartesian equation takes the opposite approach: it is a single equation Ax + By + C = 0 that every point on the line satisfies — no parameter needed. The secret ingredient is a normal vector n = (A, B): a vector drawn from the origin that is perpendicular to the line. If P(x, y) and P0(x0, y0) are on the line, then the direction-like vector P0P must be perpendicular to n, so n · P0P = 0 expands into Ax + By + C = 0 with C = −Ax0 − By0.

📖 Learn — step by step

From normal vector to Cartesian equation

Suppose the line has normal n = (A, B) and passes through P0(x0, y0). For any point P(x, y) on the line, the vector P0P = (x − x0, y − y0) runs along the line, hence is perpendicular to n. The dot product gives:

(A, B) · (x − x0, y − y0) = 0  →  Ax + By + C = 0, with C = −Ax0 − By0

Parallel, perpendicular, and angles — all from normals

Every line has infinitely many normals (all nonzero scalar multiples of each other). Two lines with normals n1, n2 are parallel if n1 = kn2 for some k ≠ 0, and perpendicular if n1 · n2 = 0. The angle between two lines is the angle between their direction vectors a and b: θ = cos⁻¹((a · b)/(|a||b|)).

Example 1 — Find the Cartesian equation of the line through A(4, −2) with normal n = (5, 3).

Solution. (Method 1 — dot product.) Let P(x, y) be a general point. Then AP = (x − 4, y + 2), and n · AP = 0 gives
(5, 3) · (x − 4, y + 2) = 0 → 5(x − 4) + 3(y + 2) = 0 → 5x + 3y − 14 = 0.
(Method 2 — substitute into Ax + By + C = 0.) With A = 5, B = 3 and point (4, −2): 5(4) + 3(−2) + C = 0 → 20 − 6 + C = 0 → C = −14.
Answer: 5x + 3y − 14 = 0.

Example 2 — Write the Cartesian equation of the line r = (3, −6) + s(−1, −4).

Solution. (Eliminate the parameter.) The parametric equations are x = 3 − s, y = −6 − 4s. From the first, s = 3 − x; substituting into the second: y = −6 − 4(3 − x) = −6 − 12 + 4x = 4x − 18.
(Check via slope.) Direction vector (−1, −4) has slope (−4)/(−1) = 4, and the line passes through (3, −6): y + 6 = 4(x − 3) → y = 4x − 18 ✓.
Answer: y = 4x − 18 (or 4x − y − 18 = 0).

Example 3 — Write the Cartesian equation of the line r = (1, 4) + s(0, 2).

Solution. (Read the geometry.) The direction vector (0, 2) points straight up, so the slope is undefined — the line is vertical. The anchor point (1, 4) has x-coordinate 1, and every point on a vertical line shares the same x-coordinate.
Answer: x = 1 (or x − 1 = 0). Eliminating s also works: x = 1 + 0s = 1 regardless of s.

Example 4 — Find the acute angle between L1: (x, y) = (2, 2) + s(−1, 3) and L2: (x, y) = (5, 1) + t(3, 4).

Solution. (Angle between direction vectors.) Let a = (−1, 3) and b = (3, 4). Then
cos θ = (a · b)/(|a||b|) = (−3 + 12)/(√10 · 5) = 9/(5√10) ≈ 0.569.
θ ≈ cos⁻¹(0.569) ≈ 55.3° (acute).
Answer: about 55.3°.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 8.2.

Question 1 — Write the Cartesian equation of the line with normal (4, 5) through A(−1, 5).

Substitute A = 4, B = 5 into 4x + 5y + C = 0: 4(−1) + 5(5) + C = 0 → −4 + 25 + C = 0 → C = −21. Answer: 4x + 5y − 21 = 0.

Question 2 — Write the Cartesian equation of the line x = 3 − t, y = −2 − 4t.

From x = 3 − t we get t = 3 − x. Substituting: y = −2 − 4(3 − x) = −2 − 12 + 4x = 4x − 14. Answer: 4x − y − 14 = 0.

Question 3 — Explain how to show x − 3y + 4 = 0 and 6x − 18y + 24 = 0 are coincident.

The normals are (1, −3) and (6, −18) = 6(1, −3) — parallel normals, so the lines are parallel. The second equation is exactly 6 times the first (6x − 18y + 24 = 6(x − 3y + 4) = 0), so every point satisfying one satisfies the other: the lines are not just parallel but coincident.

Question 4 — For what value of k are the lines L3: kx + 4y − 4 = 0 and L4: 3x − 2y − 3 = 0 perpendicular?

Normals: n3 = (k, 4), n4 = (3, −2). Perpendicular lines have perpendicular normals: n3 · n4 = 0 → 3k − 8 = 0 → k = 8/3.

📝 Lesson Summary

Key ideas

  • Cartesian equation: Ax + By + C = 0, where n = (A, B) is a normal to the line. Find C by substituting a known point.
  • Parallel lines ⇔ normals are scalar multiples. Perpendicular lines ⇔ normals' dot product is 0.
  • Angle between lines: θ = cos⁻¹((a · b)/(|a||b|)) using direction vectors — report the acute angle.
  • Vertical lines have undefined slope and take the form x = constant.

Need to know

  • One form converts to any other: eliminate the parameter to go parametric → Cartesian; read direction/normal off any form.

💡 Minds On

Studying longer usually helps — but only up to a point. Fatigue sets in, and the extra hours start paying back less and less. That "rise then fall" shape is a maximum problem, and exponential models produce it naturally. The good news: the optimization recipe from Chapter 3 is exactly the same. The only new twist is that exponential equations need logarithms to solve.

The algorithm (unchanged from Chapter 3)

NEED TO KNOW — Optimization strategy

  1. Understand the problem and state the domain.
  2. Find the critical numbers (solve f′ = 0).
  3. Evaluate the function at the critical numbers and the endpoints; compare.
  4. Identify the optimum and answer the question in context.
  5. Confirm with a graph.

The exponential shortcut: eu never vanishes

Because eu > 0 for every u, any equation of the form e(…) · (something) = 0 reduces to something = 0. And when you need to solve eu = k, take natural logs of both sides: u = ln k.

Example 1 — A student's study effectiveness t hours into a session is E(t) = 0.5[10 + te−t/20], for 0 ≤ t ≤ 30. When is effectiveness greatest?

Solution. Differentiate with the product rule:
E′(t) = 0.5[e−t/20 + t(−1/20)e−t/20] = 0.5e−t/20(1 − t/20).

Since e−t/20 is never zero, set the other factor to zero: 1 − t/20 = 0 → t = 20 (the only critical number).

Compare: E(0) = 5, E(20) ≈ 8.7, E(30) ≈ 8.3. Maximum effectiveness ≈ 8.7 after 20 hours of study. The graph confirms the maximum point (20, 8.7).

Example 2 — An ad campaign costs $5,000 per day plus a $30,000 setup. A fraction f(t) = 0.7(1 − e−0.2t) of the population responds after t days, and each responder is worth $7 of profit. The budget allows at most 34 days. How long should the campaign run to maximize profit?

Solution. Profit: P(t) = 7,000,000·f(t) − 30,000 − 5,000t = 4.9×106(1 − e−0.2t) − 30,000 − 5,000t, for 0 ≤ t ≤ 34.

P′(t) = 980,000e−0.2t − 5,000 = 0 → e−0.2t ≈ 0.005102 → take ln: −0.2t ≈ −5.278 → t ≈ 26.4 days.

Compare: P(0) = −$30,000; P(26) ≈ $4,713,000; P(34) ≈ $4,695,000. Run the campaign about 26 days for a maximum profit of ≈ $4,713,000. (After 7 days, by the way: f(7) ≈ 53% responding and profit ≈ $3,627,000.)

Example 3 — A drug's concentration in the blood is C(t) = 10(e−2t − e−3t), t in hours. When is the concentration highest in the first 5 hours?

Solution. C′(t) = 10(−2e−2t + 3e−3t) = 0 → 3e−3t = 2e−2t → 3/2 = et → t = ln(3/2) ≈ 0.405 h (≈ 24 minutes).

The endpoints give C(0) = 0 and C(5) ≈ 0, while C(0.405) ≈ 1.85 — so the maximum occurs about 24 minutes after injection.

Try these on paper first, then reveal. Modelled on Exercise 5.3.

Question 1 — Find the critical numbers of f(x) = xe−x.

f′(x) = e−x − xe−x = e−x(1 − x). Since e−x ≠ 0, the only critical number is x = 1.

Question 2 — Find the absolute maximum of f(x) = xe−x on [0, 3].

f(0) = 0; f(1) = 1/e ≈ 0.368; f(3) = 3e−3 ≈ 0.149. The absolute maximum is 1/e at x = 1.

Question 3 — True or false: "The equation e−t/20 = 0 has a solution." Justify.

False. eu > 0 for every real u — an exponential expression can never equal zero, which is exactly why critical-number equations always reduce to the other factor.

Question 4 — A rumour spreads with P(t) = 100(e−t − e−4t) percent. When is the spread rate zero (t < 3), and what is the maximum percentage?

P′(t) = 100(−e−t + 4e−4t) = 0 → 4 = e3t → t = (ln 4)/3 ≈ 0.462 h (≈ 28 min). P(0.462) ≈ 100(0.6299 − 0.1575) ≈ 47.2% — the maximum spread.

📝 Lesson Summary

Key ideas

  • Optimization follows the same 5-step algorithm as Chapter 3 — only the functions are exponential now.
  • Since eu > 0 always, f′ = 0 reduces to the other factor equal to zero.
  • Solve eu = k with natural logs: u = ln k.
  • Always answer in context (hours, days, dollars) and confirm with a graph.

Need to know

  • Don't forget the endpoints when the domain is a closed interval — the optimum may sit there.

Continuity

Nelson Calculus and Vectors 12 §1.6 — when can a graph be drawn without lifting the pencil?

🎯 Learning Goals

By the end of this lesson, you can:

  • Test whether a function is continuous at a point using the two conditions.
  • Identify the three discontinuity types: point (hole), jump, and infinite (vertical asymptote).
  • Use the facts that polynomials are continuous everywhere and rationals are continuous where defined.

💡 Minds On

Informally, continuity is the idea of being able to draw a graph without lifting your pencil — the graph has "no breaks or jumps or gaps". When we say a function is continuous at a point, we mean the graph passes through the point without a break. A graph that fails this has a break of some type at the point. 📖 Learn — step by step

What conditions must hold for a function f to be continuous at a? First, f(a) must be defined. In figures B and D above, the curves are not continuous at x = 1 precisely because they are not defined at x = 1.

Second, the function must make no jumps there — if "x is close to a", then "f(x) must be close to f(a)". That condition is satisfied when limx→a f(x) = f(a). In figure C, limx→1 f(x) does not exist, so the function is not continuous at x = 1.

Continuity at a Point. The function f(x) is continuous at x = a if f(a) is defined and if limx→a f(x) = f(a). Otherwise, f(x) is discontinuous at x = a.

The geometrical meaning: as x → a, the points (x, f(x)) on the graph converge at the point (a, f(a)), so the graph is unbroken there.

Example 1 — a. Graph f(x) = { x² − 3, if x ≤ −1; x − 1, if x > −1 }. b. Determine limx→−1 f(x). c. Determine f(−1). d. Is f continuous at x = −1? Explain.

Solution.
a. (The graph joins the parabola y = x² − 3 for x ≤ −1 to the line y = x − 1 for x > −1, meeting at (−1, −2).)
b. From the graph, limx→−1 f(x) = −2. Note: both the left-hand and right-hand limits are equal.
c. f(−1) = −2.
d. Therefore, f(x) is continuous at x = −1, since f(−1) = limx→−1 f(x).

Example 2 — Test the continuity of each function at x = 2. If a function is not continuous, give a reason why.
a. f(x) = x³ − x   b. g(x) = (x² − x − 2)/(x − 2)   c. h(x) = (x² − x − 2)/(x − 2) if x ≠ 2, and h(2) = 3   d. F(x) = 1/(x − 2)²   e. G(x) = { 4 − x², if x < 2; 3, if x ≥ 2 }

Solution.
a. f is continuous at x = 2 since f(2) = 6 = limx→2 f(x). (Polynomial functions are continuous at all real values of x.)
b. g is not continuous at x = 2 because g is not defined at this value.
c. limx→2 (x² − x − 2)/(x − 2) = limx→2 (x − 2)(x + 1)/(x − 2) = limx→2 (x + 1) = 3 = h(2). Therefore, h(x) is continuous at x = 2 — filling the hole repaired it.
d. F is not continuous at x = 2 because F(2) is not defined.
e. limx→2⁻ G(x) = limx→2⁻ (4 − x²) = 0 and limx→2⁺ G(x) = limx→2⁺ (3) = 3. Since limx→2 G(x) does not exist, G is not continuous at x = 2 (a jump).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 1.6.

Question 1 — How can looking at a graph tell you where a function is continuous?

Look for breaks: holes (missing points), jumps (the graph leaps), and vertical asymptotes (the graph shoots off). Where none occur, the function is continuous.

Question 2 — Is f(x) = (x² − x − 6)/(x − 3) continuous at x = 3?

No — f(3) is undefined (0/0), so the first continuity condition fails. (The limit exists: it equals 5.)

Question 3 — Sketch h(x) = { x − 1, if x < 3; 5 − x, if x ≥ 3 }. Is h continuous everywhere? Explain.

limx→3⁻ h(x) = 2 and limx→3⁺ h(x) = 2 = h(3), so yes — the two pieces meet at (3, 2) with no break.

Question 4 — Name the three discontinuity types and give an example of each.

Point (removable): (x² − 4)/(x − 2) at x = 2 (hole). Jump: a piecewise function whose one-sided limits differ. Infinite: 1/(x − 2)² at x = 2 (vertical asymptote).

📝 Lesson Summary

Key ideas

  • A function f is continuous at x = a if: f(a) is defined · limx→a f(x) exists · limx→a f(x) = f(a).
  • A function that is not continuous has some type of break in its graph: a hole, a jump, or a vertical asymptote.

Need to know

  • All polynomial functions are continuous for all real numbers.
  • A rational function h(x) = f(x)/g(x) is continuous at x = a if g(a) ≠ 0; in simplified form it has a discontinuity at the zeros of the denominator.
  • When the one-sided limits are not equal, the limit does not exist and the function is not continuous there.

📖 Learn — step by step

Higher-order derivatives

The function y = f(x) has a first derivative y = f′(x). The second derivative of y = f(x) is the derivative of y = f′(x). For example, the derivative of f(x) = 10x⁴ is f′(x) = 40x³; differentiating again gives f″(x) = 120x². For y = 2x³ − 5x², the first derivative is dy/dx = 6x² − 10x and the second derivative is d²y/dx² = 12x − 10.

Note the superscripts in the second derivative: the second derivative is the derivative of the first derivative — that is, d/dx(dy/dx) = d²y/dx². Other notations for the first and second derivatives of y = f(x) are dy/dx = f′(x) = y′ and d²y/dx² = f″(x) = y″.

Example 1 — Determine the second derivative of f(x) = x/(1 + x) when x = 1.

Solution. Write f(x) = x/(1 + x) as a product, and differentiate.
f(x) = x(x + 1)⁻¹
f′(x) = (1)(x + 1)⁻¹ + (x)(−1)(x + 1)⁻²(1)   (Product and power of a function rule)
= 1/(x + 1) − x/(x + 1)²
= 1(x + 1)/(x + 1)² − x/(x + 1)²   (Simplify)
= (x + 1 − x)/(x + 1)²
= 1/(1 + x)²   (Rewrite as a power function)
= (1 + x)⁻²
Differentiating again to determine the second derivative,
f″(x) = −2(1 + x)⁻³(1)   (Power of a function rule)
= −2/(1 + x)³.
When x = 1, f″(1) = −2/(1 + 1)³   (Evaluate)
= −2/8
= −1/4.

Question 1 — Find the second derivative of f(x) = x¹⁰ + 3x⁶.

f′(x) = 10x⁹ + 18x⁵; f″(x) = 90x⁸ + 90x⁴.

Question 2 — Find the second derivative of f(x) = √x.

f(x) = x^(1/2); f′(x) = (1/2)x^(−1/2); f″(x) = −(1/4)x^(−3/2).

Question 3 — Find the second derivative of f(x) = (1 − x)².

Expand: 1 − 2x + x²; f′(x) = −2 + 2x; f″(x) = 2.

Question 4 — Find f″(1) for f(x) = 2x/(x + 5).

f′(x) = 10/(x + 5)² = 10(x + 5)⁻²; f″(x) = −20(x + 5)⁻³; f″(1) = −20/216 = −5/54.

📝 Lesson Summary

Key ideas

  • The second derivative is the derivative of the first derivative.
  • Notations: f″(x), y″, d²y/dx² — the superscript records "derivative of the derivative".

Need to know

  • Simplify f′(x) (e.g., rewrite as a power function) before differentiating again.

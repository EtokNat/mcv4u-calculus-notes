Scalar Multiplication and Collinear Vectors

Nelson Calculus and Vectors 12 §6.3 (with the laws of §6.4) — stretching, shrinking, and flipping arrows.

🎯 Learning Goals

By the end of this lesson, you can:

  • Describe how ka changes a vector's magnitude and direction for positive, negative, and zero k.
  • Test whether vectors are collinear and build unit vectors in any direction.
  • Simplify vector expressions with the commutative, associative, and distributive laws.

💡 Minds On

Double a plane's velocity and it goes twice as fast the same way. Halve it and it crawls along the same heading. Reverse it and it flies the same speed backwards. One operation — multiplying by a plain number — controls length and direction separately. That number is called a scalar, and today it becomes a tool.

📖 Learn — step by step

Key term — Scalar multiplication: for a nonzero vector a and a real number k, the vector ka has magnitude |k|·|a|; it points the same way as a if k > 0 and the opposite way if k < 0.
  • The four cases. k > 1 stretches (same direction); 0 < k < 1 shrinks (same direction); k < 0 flips to the opposite direction (shrinking if |k| < 1, stretching if |k| > 1); k = 0 gives the zero vector: 0a = 0.
  • Collinear vectors. Vectors that lie on the same straight line (possibly after sliding) are collinear — "parallel" means the same thing here. Every scalar multiple of a is collinear with a, and the test runs both ways: u and v are collinear exactly when u = kv for some nonzero scalar k.
  • Unit vectors. (1/|x|)·x is the unit vector in x's direction: length 1, same heading. It captures "pure direction" — useful whenever only the heading matters.
  • The algebra still works. Vector addition and scalar multiplication obey the familiar laws, so expressions simplify the way number expressions do:
    • Commutative: a + b = b + a
    • Associative: (a + b) + c = a + (b + c)
    • Distributive: k(a + b) = ka + kb; (m + n)a = ma + na; m(na) = (mn)a; a + 0 = a

Example 1 — Unit vectors x and y make a 30° angle with each other. (a) Find |2x − y|. (b) Find the direction of 2x − y relative to x.

Solution. Draw 2x and −y head-to-tail.
(a) Cosine law: |2x − y|² = |2x|² + |−y|² − 2|2x||−y|cos 30° = 4 + 1 − 2(2)(1)(√3/2) = 5 − 2√3.
So |2x − y| = √(5 − 2√3) ≈ 1.24.
(b) Sine law: sin θ / |−y| = sin 30° / |2x − y| → sin θ = sin 30° / 1.24 ≈ 0.403 → θ ≈ 23.8°.
The vector 2x − y points 23.8° clockwise from x.

Example 2 — |u| = 4, |v| = 5, and the angle between u and v is 120°. Find the unit vector in the direction of u + v.

Solution. First the length: |u + v|² = 16 + 25 − 2(4)(5)cos 60° = 41 − 20 = 21, so |u + v| = √21 (the triangle angle is the 60° supplement).
The unit vector is (1/|u + v|)(u + v) = (1/√21)(u + v) — same direction, length exactly 1.

Example 3 — Simplify 3(2a + b + c) − (a + 3b − 2c).

Solution. Distribute, then commute and collect:
= 6a + 3b + 3c − a − 3b + 2c (distributive)
= 6a − a + 3b − 3b + 3c + 2c (commutative)
= 5a + 5c (collect like terms).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercises 6.3–6.4.

Question 1 — Vector v has |v| = 2. Describe −(2/3)v: direction and magnitude.

Negative scalar → opposite direction; magnitude |−2/3| × 2 = 4/3.

Question 2 — Are 2a and −3a collinear? Are 2a and 3b (a, b noncollinear) collinear?

2a and −3a are collinear — both are scalar multiples of a (one is (−3/2) times the other). 2a and 3b are not — no nonzero scalar turns a into b when a and b aren't collinear.

Question 3 — Explain why the equation a = 2|b| is meaningless.

The left side is a vector (has direction); the right side is a scalar (just a number). A vector can never equal a plain number — it's a type mismatch.

Question 4 — Simplify 2(a − 3b) − 3(−2a − 7b).

= 2a − 6b + 6a + 21b = 8a + 15b.

📝 Lesson Summary

Key ideas

  • ka: |k| scales the length; k > 0 keeps direction, k < 0 reverses it, k = 0 gives the zero vector.
  • Collinear ⟺ one is a nonzero scalar multiple of the other. Unit vector in x's direction: (1/|x|)x.
  • Vector algebra obeys the commutative, associative, and distributive laws — simplify freely.

Need to know

  • Never equate a vector with a scalar — |b| is a number, b is an arrow.

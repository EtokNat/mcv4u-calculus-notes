📖 Learn — step by step

Reading an applied graph

On a graph of value versus time, the calculus features become decisions:

  • Local minimum → BUY. The value has finished falling and is about to rise — the cheapest moment.
  • Local maximum → SELL. The value has finished rising and is about to fall — the most profitable moment.
  • Inflection point → TREND CHANGE. The rate of growth stops increasing and starts decreasing (or vice versa) — momentum shifts even though the value is still climbing.

Example 1 — The graph above shows the value of an investment over 10 months. Identify the buy point, the sell point, and the trend-change point, and explain each.

Solution.
• B (local minimum): the lowest value on the curve — buying here means purchasing at the cheapest price before the rise.
• S (local maximum): the highest value — selling here locks in the largest gain before the decline.
• C (inflection point): to the left of C the curve is concave up (growth accelerating); to the right it is concave down (growth decelerating). A careful investor notices at C that momentum is fading, even though the value is still rising.

Sketching from a feature list

The algorithm also runs in reverse: given key features, draw a possible graph. (It won't be unique — many functions can share the same features. Any smooth curve honouring every feature earns full marks.)

Example 2 — Sketch a possible graph of a function with these features: increasing on (−∞, 0), decreasing on (0, ∞); local maximum at (0, 3); concave down everywhere; x-intercepts at x = −2 and x = 2.

Solution. Start with the anchor points: mark (0, 3), (−2, 0), (2, 0). The curve must rise toward (0, 3) from the left and fall away to the right — a hill shape. "Concave down everywhere" means it bends downward throughout, like an upside-down bowl, with no wiggles. Draw a smooth hill through the three points, flattening at the peak (horizontal tangent at the local max). Any smooth dome through those points with a flat top at (0, 3) is correct.

Back to optimization — with the whole picture

In Unit 3 you optimized: build a function, find where its derivative is zero, and pick the best value. Curve sketching adds the rest of the story — including the inflection point, which in applied settings marks diminishing returns: the input level beyond which each extra unit buys you less and less.

Example 3 — A manufacturer's profit (in thousands of dollars) for producing x thousand units is P(x) = −2x³ + 30x² − 96x + 200, x ≥ 0. Find the production level maximizing profit, and interpret the inflection point.

Solution.
P′(x) = −6x² + 60x − 96 = −6(x² − 10x + 16) = −6(x − 2)(x − 8). Critical numbers: x = 2, x = 8.
P″(x) = −12x + 60.
• P″(2) = 36 > 0 → local minimum at x = 2 (P(2) = 112).
• P″(8) = −36 < 0 → local maximum at x = 8: P(8) = −2(512) + 30(64) − 96(8) + 200 = 328. Maximum profit is $328,000 at 8,000 units.

Inflection: P″(x) = 0 at x = 5; P(5) = 220. For x < 5, marginal profit P′(x) is increasing; after x = 5 it is decreasing. So x = 5 is where diminishing returns set in — beyond 5,000 units, each additional thousand units adds less profit than the one before, even though total profit keeps climbing until x = 8.

✅ Check Your Understanding

Try these on paper first, then reveal.

Question 1 — On a stock-price graph, what does a local maximum tell an investor, and why?

It marks a good time to sell: the price has finished rising and is about to fall, so selling there locks in the largest gain.

Question 2 — What does an inflection point on a profit graph mean in practical terms?

It is where profit stops accelerating and starts decelerating — marginal profit is at its maximum there. Beyond it, diminishing returns set in: extra production still adds profit, but less and less per unit.

Question 3 — A function has f′ > 0 and f″ < 0 on an interval. Describe the graph there.

The graph is increasing (f′ > 0) but concave down (f″ < 0) — it rises at a decreasing rate, like the right half of a hill that is levelling off.

Question 4 — Give an example of a critical point that is neither a local max nor a local min, and verify with a sign check.

f(x) = x³ at x = 0: f′(x) = 3x² = 0 at x = 0 (critical number), but f′(x) ≥ 0 on both sides — no sign change, so (0, 0) is neither a max nor a min; the graph climbs straight through.

📝 Lesson Summary

Key ideas

  • On applied graphs: local min → buy, local max → sell, inflection → momentum/trend change.
  • You can sketch from a feature list — the result isn't unique, but every feature must be honoured.
  • Optimization finds the peak; curve sketching adds the inflection point, marking diminishing returns.

LESSON 9.6

Intersections of Planes and Distances

Nelson Calculus and Vectors 12 §§9.3–9.6 — two planes meet in a line; three planes tell richer stories; then the shortest distances.

🎯 Learning Goals

By the end of this lesson, you can:

  • Find the line of intersection of two planes and classify three-plane configurations (point, line, coincident, prism, parallel).
  • Compute the distance from a point to a line (in R2 and R3) and from a point to a plane.
  • Compute the distance between skew lines by two methods.

💡 Minds On

Two nonparallel planes in R3 always meet in a line — solve their two Cartesian equations together, let one variable be a free parameter t, and read off the line's parametric equations. (Its direction vector is n1 × n2, perpendicular to both normals.) Three planes are richer: they can meet at a single point, share a line, be coincident — or be inconsistent with no common point at all (a triangular prism, parallel configurations). The algebra tells you which: after elimination, 0 = nonzero means inconsistent; 0 = 0 means dependent (infinitely many solutions).

📖 Learn — step by step

The intersection of two planes

Two planes: parallel distinct (normals are multiples, constants don't match — no intersection), coincident (one equation is a multiple of the other — the whole plane), or intersecting in a line (normals not parallel). For the line: set one variable (preferably one with coefficient 1 or −1) equal to a parameter t, solve the 2×2 system for the other two, and write the parametric equations.

The intersection of three planes

Solve the 3×3 system by elimination (§9.2). Consistent: a unique point (three planes through one point), a line (all three contain one line — elimination leaves two independent equations), or the whole plane (all three coincident — 0 = 0 everywhere). Inconsistent (0 = nonzero appears): a triangular prism (pairwise intersections are three parallel lines), two parallel planes cut by a third, all three parallel, or two coincident with the third parallel.

Distances: point–line, point–plane, skew lines

  • Point to line in R2: for P(x0, y0) and Ax + By + C = 0: d = |Ax0 + By0 + C| / √(A² + B²).
  • Point to line in R3: for point Q and the line through P with direction m: d = |m × PQ| / |m| — the area of the parallelogram spanned by m and PQ, divided by its base.
  • Point to plane: for P(x0, y0, z0) and Ax + By + Cz + D = 0: d = |Ax0 + By0 + Cz0 + D| / √(A² + B² + C²).
  • Skew lines — two methods: (1) build parallel planes, one containing each line, and take the distance between the planes; (2) project the connecting vector onto the common perpendicular: d = |(m1 × m2) · P1P2| / |m1 × m2|.

Example 1 — Find the line of intersection of π1: x + 2y − z = 1 and π2: 2x − y + z = 3.

Solution. (Check normals.) n1 = (1, 2, −1), n2 = (2, −1, 1): not scalar multiples → the planes intersect in a line.
(Set z = t — it has coefficient ±1 in both.) Then x + 2y = 1 + t and 2x − y = 3 − t.
(Solve.) From the first: x = 1 + t − 2y. Substitute: 2(1 + t − 2y) − y = 3 − t → 2 + 2t − 5y = 3 − t → 5y = −1 + 3t → y = −1/5 + 3t/5. Then x = 1 + t − 2(−1/5 + 3t/5) = 1 + t + 2/5 − 6t/5 = 7/5 − t/5.
(Check at t = 0.) Point (7/5, −1/5, 0): π1: 7/5 − 2/5 = 1 ✓; π2: 14/5 + 1/5 = 3 ✓.
Answer: x = 7/5 − t/5, y = −1/5 + 3t/5, z = t, t ∈ R.

Example 2 — Classify the intersection of the three planes π1: x + y + z = 1, π2: 2x + 2y + 2z = 5, π3: x − y + z = 3.

Solution. (Compare π1 and π2.) The normal of π2, (2, 2, 2), is 2× the normal of π1, (1, 1, 1) — but the constants 5 and 1 are not in ratio 2. So π1 ∥ π2, distinct.
(Conclusion.) Two of the planes are parallel and distinct, so no point can lie on all three — the system is inconsistent: no common intersection (two parallel planes cut by a third).
Answer: inconsistent — no point lies on all three planes.

Example 3 — Find the distance from P(1, 2, 3) to the plane 2x − y + 2z = 4, and the coordinates of the closest point on the plane.

Solution. (Formula.) d = |2(1) − (2) + 2(3) − 4| / √(4 + 1 + 4) = |2 − 2 + 6 − 4| / 3 = 2/3.
(Closest point: travel along the normal.) The normal is n = (2, −1, 2). The line through P in the normal direction: r = (1, 2, 3) + t(2, −1, 2). Meet it with the plane: 2(1 + 2t) − (2 − t) + 2(3 + 2t) = 4 → 2 + 4t − 2 + t + 6 + 4t = 4 → 6 + 9t = 4 → t = −2/9.
Point: (1 − 4/9, 2 + 2/9, 3 − 4/9) = (5/9, 20/9, 23/9). (Check: 2(5/9) − 20/9 + 2(23/9) = (10 − 20 + 46)/9 = 36/9 = 4 ✓.)
Answer: distance 2/3; closest point (5/9, 20/9, 23/9).

Example 4 — Find the distance between the skew lines L1: r = (1, 0, 0) + t(1, 1, 0) and L2: r = (0, 1, 1) + s(0, 1, 1).

Solution. (Method 2 — project onto the common perpendicular.) m1 = (1, 1, 0), m2 = (0, 1, 1).
m1 × m2 = |i j k; 1 1 0; 0 1 1| = (1·1 − 0·1, −(1·1 − 0·0), 1·1 − 1·0) = (1, −1, 1); |m1 × m2| = √3.
(Connecting vector.) Take P1 = (1, 0, 0) on L1 and P2 = (0, 1, 1) on L2: P1P2 = (−1, 1, 1).
(Project.) d = |(1, −1, 1) · (−1, 1, 1)| / √3 = |−1 − 1 + 1| / √3 = 1/√3 = √3/3 ≈ 0.577.
(Method 1 — parallel planes, check.) A plane containing L1 with normal (1, −1, 1): x − y + z = 1 (through (1,0,0)). A parallel plane containing L2: x − y + z = 0 − 1 + 1 = 0 (through (0,1,1)). Distance between x − y + z = 1 and x − y + z = 0: |1 − 0|/√3 = 1/√3 ✓.
Answer: √3/3 ≈ 0.577.

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercises 9.3–9.6.

Question 1 — Find the line of intersection of π1: 2x − y + 3z = 5 and π2: x + 4y − z = 2.

Normals (2, −1, 3) and (1, 4, −1): not multiples → a line. Set z = t: 2x − y = 5 − 3t, x + 4y = 2 + t. From the second: x = 2 + t − 4y. Substitute: 2(2 + t − 4y) − y = 5 − 3t → 4 + 2t − 9y = 5 − 3t → 9y = −1 + 5t → y = −1/9 + 5t/9; then x = 2 + t − 4(−1/9 + 5t/9) = 2 + t + 4/9 − 20t/9 = 22/9 − 11t/9. Answer: x = 22/9 − 11t/9, y = −1/9 + 5t/9, z = t.

Question 2 — The planes x + y + z = 1, 2x + 2y + 2z = 2, 3x + 3y + 3z = 3: what is their intersection?

Each equation is a nonzero multiple of x + y + z = 1 (×2, ×3). All three describe the same (coincident) plane — infinitely many common points: the whole plane.

Question 3 — Find the distance from Q(1, 2, 3) to the line r = (1, 0, −1) + t(2, 1, 2).

m = (2, 1, 2), |m| = 3. Take P = (1, 0, −1) on the line: PQ = (0, 2, 4). m × PQ = |i j k; 2 1 2; 0 2 4| = (1·4 − 2·2, −(2·4 − 2·0), 2·2 − 1·0) = (0, −8, 4). |m × PQ| = √(0 + 64 + 16) = √80 = 4√5. d = 4√5/3 ≈ 2.98.

Question 4 — Find the distance between the parallel planes 2x − 3y + 6z = 1 and 2x − 3y + 6z = 8.

Same normal (2, −3, 6), |n| = √(4 + 9 + 36) = 7. Pick a point on the first plane, e.g. (1/2, 0, 0): d = |2(1/2) − 0 + 0 − 8|/7 = |1 − 8|/7 = 1.

📝 Lesson Summary

Key ideas

  • Two planes: parallel distinct / coincident / intersecting in a line (free parameter + 2×2 solve).
  • Three planes: consistent (point, line, coincident) or inconsistent (prism, parallel cases) — elimination's 0 = nonzero vs 0 = 0 tells you.
  • Distances: point–line R2: |Ax0+By0+C|/√(A²+B²); point–line R3: |m × PQ|/|m|; point–plane: |Ax0+By0+Cz0+D|/√(A²+B²+C²).
  • Skew lines: parallel containing planes, or project onto m1 × m2.

Need to know

  • Always verify an intersection line by plugging a point back into both plane equations.

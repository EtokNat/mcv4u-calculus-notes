Properties of Limits

Nelson Calculus and Vectors 12 §1.5 — the algebraic toolbox: substitution, factoring, rationalizing, and more.

🎯 Learning Goals

By the end of this lesson, you can:

  • Evaluate limits using the seven limit properties (including direct substitution for polynomials).
  • Recognize the indeterminate form 0/0 and resolve it by factoring, rationalizing, or a change of variable.
  • Use one-sided limits to show a limit does not exist.

💡 Minds On

Saying limx→a f(x) = L means the values of f(x) get closer and closer to L as x gets closer and closer to a — from either side, with x ≠ a. When finding a limit there is no need to consider x = a; in fact, f(a) need not even be defined. The only thing that matters is the behaviour of f(x) near x = a.

📖 Learn — step by step

Example 1 — Find limx→2 (3x² + 4x − 1).

Solution. It seems clear that when x is close to 2, 3x² is close to 12, and 4x is close to 8. Therefore, it appears that limx→2 (3x² + 4x − 1) = 12 + 8 − 1 = 19.

In Example 1 the limit was found intuitively. Limits can also be evaluated with the following properties of limits (provable from the formal definition — the proofs belong to more advanced courses). For any real number a, suppose f and g both have limits that exist at x = a:

Properties of Limits.
  1. limx→a k = k, for any constant k
  2. limx→a x = a
  3. limx→a [f(x) ± g(x)] = limx→a f(x) ± limx→a g(x)
  4. limx→a [c f(x)] = c[limx→a f(x)], for any constant c
  5. limx→a [f(x) g(x)] = [limx→a f(x)][limx→a g(x)]
  6. limx→a f(x)/g(x) = [limx→a f(x)]/[limx→a g(x)], provided limx→a g(x) ≠ 0
  7. limx→a [f(x)]n = [limx→a f(x)]n, for any rational number n

Example 2 — Evaluate limx→2 (3x² + 4x − 1) using the limit properties.

Solution.
limx→2 (3x² + 4x − 1) = limx→2 (3x²) + limx→2 (4x) − limx→2 (1)
= 3 limx→2 (x²) + 4 limx→2 (x) − 1
= 3[limx→2 x]² + 4(2) − 1
= 3(2)² + 8 − 1
= 19.
Note: if f is a polynomial function, then limx→a f(x) = f(a).

Example 3 — Evaluate limx→−1 (x² − 5x + 2)/(2x³ + 3x + 1).

Solution.
limx→−1 (x² − 5x + 2)/(2x³ + 3x + 1) = [limx→−1 (x² − 5x + 2)]/[limx→−1 (2x³ + 3x + 1)]
= [(−1)² − 5(−1) + 2]/[2(−1)³ + 3(−1) + 1]
= 8/(−4)
= −2.

Example 4 — Evaluate limx→5 √(x²/(x − 1)).

Solution.
limx→5 √(x²/(x − 1)) = √[limx→5 x²/(x − 1)]
= √[(limx→5 x²)/(limx→5 (x − 1))]
= √(25/4)
= 5/2.

When substitution gives 0/0

Sometimes limx→a f(x) cannot be found by direct substitution — particularly when substitution produces the indeterminate form 0/0. In such cases, look for an equivalent function that agrees with f for all values except at x = a, then substitute into that.

Example 5 — Evaluate limx→3 (x² − 2x − 3)/(x − 3) by factoring.

Solution. Substitution produces the indeterminate form 0/0. Simplify by factoring and reducing:
limx→3 (x² − 2x − 3)/(x − 3) = limx→3 (x + 1)(x − 3)/(x − 3) = limx→3 (x + 1).
The reduction is valid only if x ≠ 3 — but a limit only cares about x approaching 3, not x = 3. Therefore limx→3 (x² − 2x − 3)/(x − 3) = limx→3 (x + 1) = 4.

Example 6 — Evaluate limx→0 (√(x + 1) − 1)/x by rationalizing.

Solution. Rationalizing the numerator (or denominator) can turn an indeterminate form into one that is not. Substitution gives 0/0, so we rationalize:
limx→0 (√(x + 1) − 1)/x = limx→0 [(√(x + 1) − 1)/x] × [(√(x + 1) + 1)/(√(x + 1) + 1)]   (rationalize the numerator)
= limx→0 [(x + 1) − 1]/[x(√(x + 1) + 1)]
= limx→0 x/[x(√(x + 1) + 1)]   (simplify)
= limx→0 1/[√(x + 1) + 1]   (evaluate)
= 1/2.

Example 7 — Evaluate limx→0 [(x + 8)1/3 − 2]/x by a change of variable.

Solution. This quotient is indeterminate (0/0) when x = 0, and rationalizing (x + 8)1/3 − 2 is not easy. Instead, substitute: let u = (x + 8)1/3. Then u³ = x + 8 and x = u³ − 8. As x → 0, u → 2. The limit becomes
limx→0 [(x + 8)1/3 − 2]/x = limu→2 (u − 2)/(u³ − 8)   (factor)
= limu→2 (u − 2)/[(u − 2)(u² + 2u + 4)]   (simplify)
= limu→2 1/(u² + 2u + 4)   (evaluate)
= 1/12.

Example 8 — Evaluate limx→2 |x − 2|/(x − 2), with a graph.

Solution. Write the function piecewise: |x − 2|/(x − 2) equals 1 when x > 2 and −1 when x < 2 (f(2) is undefined). The graph is two horizontal rays at heights 1 and −1.
limx→2⁻ f(x) = limx→2⁻ (−1) = −1;   limx→2⁺ f(x) = limx→2⁺ (1) = 1.
Since the left-hand and right-hand limits are not the same, limx→2 |x − 2|/(x − 2) does not exist.

Example 9 — a. Evaluate limx→3⁻ √(9 − x²). b. Explain why the limit as x → 3⁺ cannot be determined. c. What can you conclude about limx→3 √(9 − x²)?

Solution.
a. The graph of f(x) = √(9 − x²) is the semicircle below. From the graph, the left-hand limit at x → 3 is 0: limx→3⁻ √(9 − x²) = 0.
b. The function is not defined for x > 3.
c. limx→3 √(9 − x²) does not exist, because the function is not defined on both sides of 3.

Try these on paper first, then reveal. Modelled on Exercise 1.5.

Question 1 — Evaluate limx→−1 (x⁴ + x³ + x²).

Polynomial — substitute: 1 − 1 + 1 = 1.

Question 2 — Evaluate limx→2 (4 − x²)/(2 − x).

0/0 — factor: (2 − x)(2 + x)/(2 − x) = 2 + x → 4.

Question 3 — Evaluate limx→4 (√x − 2)/(x − 4).

Rationalize the numerator: [(√x − 2)(√x + 2)]/[(x − 4)(√x + 2)] = 1/(√x + 2) → 1/4.

Question 4 — Evaluate limx→5⁻ |x − 5|/(x − 5).

For x < 5, |x − 5| = −(x − 5), so the quotient is −1.

📝 Lesson Summary

Key ideas

  • If f is a polynomial, then limx→a f(x) = f(a) — just substitute.
  • If substituting x = a gives the indeterminate form 0/0, find an equivalent function that matches f everywhere except at x = a, then substitute into that.

Need to know — algebraic techniques

  • Direct substitution · factoring · rationalizing · one-sided limits · change of variable.
  • A graph or table of values can always check your result.

The Chain Rule

Nelson Calculus and Vectors 12 §2.5 — differentiating composite functions: the derivative of the outside times the derivative of the inside.

🎯 Learning Goals

By the end of this lesson, you can:

  • Form and decompose composite functions (f∘g)(x) = f(g(x)).
  • Apply the chain rule in function and Leibniz notation.
  • Use the power of a function rule (real exponents) and combine rules on complex expressions.

💡 Minds On

One way of combining functions is composition: start with x in the domain of g, find g(x), then take the value of f at g(x) — the result is h(x) = f(g(x)), the composite function of f and g, denoted (f∘g). The chain rule tells us how to differentiate it.

📖 Learn — step by step

Definition of a Composite Function. Given two functions f and g, the composite function (f∘g) is defined by (f∘g)(x) = f(g(x)).

Example 1 — If f(x) = √x and g(x) = x + 5, find:
a. f(g(4))   b. g(f(4))   c. f(g(x))   d. g(f(x))

Solution.
a. Since g(4) = 9, f(g(4)) = f(9) = 3.
b. Since f(4) = 2, g(f(4)) = g(2) = 7. Note: f(g(4)) ≠ g(f(4)) — composition is not commutative.
c. f(g(x)) = f(x + 5) = √(x + 5).
d. g(f(x)) = g(√x) = √x + 5. Note: f(g(x)) ≠ g(f(x)).

The Chain Rule. If f and g have derivatives, the composite h(x) = f(g(x)) has derivative h′(x) = f′(g(x))·g′(x).
In words: "the derivative of a composite function is the product of the derivative of the outer function evaluated at the inner function and the derivative of the inner function."
Proof idea: multiply and divide the difference quotient by g(x + h) − g(x); the two factors tend to f′(g(x)) and g′(x). (This assumes g(x + h) − g(x) ≠ 0 — the fully general proof belongs to advanced courses.)

Example 2 — Differentiate h(x) = (x² + x)³.

Solution. The inner function is g(x) = x² + x, and the outer function is f(x) = x³.
The derivative of the inner function is g′(x) = 2x + 1.
The derivative of the outer function is f′(x) = 3x².
The derivative of the outer function evaluated at the inner function is f′(x² + x) = 3(x² + x)².
By the chain rule, h′(x) = 3(x² + x)²(2x + 1).

The Chain Rule in Leibniz Notation. If y is a function of u and u is a function of x (so y is a composite function), then dy/dx = (dy/du)·(du/dx), provided both derivatives exist.
As rates of change: if y depends on x through the intermediate variable u, then the rate of change of y w.r.t. x equals the rate of change of y w.r.t. u times the rate of change of u w.r.t. x.

Example 3 — If y = u³ − 2u + 1, where u = 2√x, find dy/dx at x = 4.

Solution. Using the chain rule, dy/dx = (dy/du)(du/dx) = (3u² − 2)[2·(1/2)x^(−1/2)] = (3u² − 2)(1/√x).
When x = 4, u = 2√4 = 4, and dy/dx = [3(4)² − 2](1/√4) = (46)(1/2) = 23.

Example 4 — An environmental study suggests the average daily level of carbon monoxide in a community is C(p) = √(0.5p² + 17) parts per million, where p (thousands) is the population. The population t years from now is p(t) = 3.1 + 0.1t² thousand. At what rate will the carbon monoxide level be changing three years from now?

Solution. We need dC/dt at t = 3. By the chain rule, dC/dt = (dC/dp)(dp/dt).
dC/dp = d/dp[(0.5p² + 17)^(1/2)] = (1/2)(0.5p² + 17)^(−1/2)(0.5)(2p); dp/dt = 0.2t.
When t = 3, p(3) = 3.1 + 0.1(3)² = 4. So dC/dt = [(1/2)(0.5(4)² + 17)^(−1/2)(0.5)(2)(4)][0.2(3)] = 0.24.
Since dC/dt is positive, the carbon monoxide level will be increasing at 0.24 parts per million per year three years from now.

Example 5 — If y = (x² − 5)⁷, find dy/dx.

Solution. The inner function is g(x) = x² − 5, the outer is f(x) = x⁷. By the chain rule,
dy/dx = 7(x² − 5)⁶(2x) = 14x(x² − 5)⁶.

Example 5 is the special case where the outer function is a power, y = [g(x)]ⁿ — a generalization of the integer power-of-a-function rule from Lesson 2.4:

Power of a Function Rule. If n is a real number and u = g(x), then d/dx(uⁿ) = nuⁿ⁻¹·du/dx, or d/dx[g(x)]ⁿ = n[g(x)]ⁿ⁻¹·g′(x).

Example 6 — Find the equation of the tangent to f(x) = 8/(x² + 4) at the point (2, 1).

Solution. Write f(x) = 8(x² + 4)⁻¹. By the power of a function rule, f′(x) = −8(x² + 4)⁻²(2x).
The slope at (2, 1) is f′(2) = −8(4 + 4)⁻²(4) = −32/(8)² = −0.5.
The tangent is y − 1 = −1/2(x − 2), or x + 2y − 4 = 0.

Example 7 — Differentiate h(x) = (x² + 3)⁴(4x − 5)³. Express your answer in simplified factored form.

Solution. Use the product rule and the chain rule.
h′(x) = d/dx[(x² + 3)⁴]·(4x − 5)³ + d/dx[(4x − 5)³]·(x² + 3)⁴   (Product rule)
= [4(x² + 3)³(2x)]·(4x − 5)³ + [3(4x − 5)²(4)]·(x² + 3)⁴   (Chain rule)
= 8x(x² + 3)³(4x − 5)³ + 12(4x − 5)²(x² + 3)⁴   (Simplify)
= 4(x² + 3)³(4x − 5)²[2x(4x − 5) + 3(x² + 3)]   (Factor)
= 4(x² + 3)³(4x − 5)²(11x² − 10x + 9).

Example 8 — Determine the derivative of g(x) = ((1 + x²)/(1 − x²))¹⁰.

Solution. Two routes both work — product + chain, or chain + quotient. Writing g(x) = (1 + x²)¹⁰(1 − x²)⁻¹⁰ and using the product and chain rules:
g′(x) = 10(1 + x²)⁹(2x)(1 − x²)⁻¹⁰ + (1 + x²)¹⁰(−10)(1 − x²)⁻¹¹(−2x)
= 20x(1 + x²)⁹(1 − x²)⁻¹⁰ + 20x(1 + x²)¹⁰(1 − x²)⁻¹¹   (Simplify)
= 20x(1 + x²)⁹(1 − x²)⁻¹¹[(1 − x²) + (1 + x²)]   (Factor)
= 20x(1 + x²)⁹(1 − x²)⁻¹¹(2)   (Rewrite with positive exponents)
= 40x(1 + x²)⁹/(1 − x²)¹¹.

Try these on paper first, then reveal. Modelled on Exercise 2.5.

Question 1 — Differentiate (do not expand): (a) (2x + 3)⁴; (b) (x² − 4)³; (c) √(x² − 3).

(a) 4(2x + 3)³(2) = 8(2x + 3)³. (b) 3(x² − 4)²(2x) = 6x(x² − 4)². (c) (1/2)(x² − 3)^(−1/2)(2x) = x/√(x² − 3).

Question 2 — Find the tangent slope to y = (3x − x²)⁻² at (2, 1/4).

y′ = −2(3x − x²)⁻³(3 − 2x); at x = 2: −2(2)⁻³(−1) = 1/4.

Question 3 — If y = 3u² − 5u + 2 and u = x² − 1, find dy/dx at x = 2.

dy/dx = (6u − 5)(2x); at x = 2, u = 3: (13)(4) = 52.

Question 4 — Differentiate y = x²(1 − x³)/(1 + x)³.

Combine product, quotient, and chain rules; one clean route: treat as x²(1 − x³)(1 + x)⁻³ and apply the extended product rule with the power of a function rule on each factor.

📝 Lesson Summary

Key idea

  • Chain rule: if y = f(g(x)), then h′(x) = f′(g(x))·g′(x); in Leibniz notation, dy/dx = (dy/du)(du/dx).

Need to know

  • Power of a function rule: d/dx[g(x)]ⁿ = n[g(x)]ⁿ⁻¹·g′(x), for any real n.
  • Composition is not commutative: f(g(x)) ≠ g(f(x)) in general.
  • Complex expressions often need the product, quotient, and chain rules together.

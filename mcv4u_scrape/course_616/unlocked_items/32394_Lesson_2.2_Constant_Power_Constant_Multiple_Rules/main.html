Constant, Power & Constant Multiple Rules

Nelson Calculus and Vectors 12 §2.2 (part 1) — shortcut rules that replace tedious limit computations.

🎯 Learning Goals

By the end of this lesson, you can:

  • State and apply the constant function rule, the power rule, and the constant multiple rule.
  • Rewrite roots and reciprocals as powers before differentiating.
  • See how each rule follows from the limit definition.

💡 Minds On

Computing derivatives from the limit definition, as in Lesson 2.1, is tedious and time-consuming. In this section we develop rules that simplify differentiation — each one proved from the definition, so you can trust them and rarely use first principles again.

📖 Learn — step by step

Begin with the constant function f(x) = k. Its graph is a horizontal line with slope zero at each point, so the derivative should be zero — for example, if f(x) = −4, then f′(3) = 0.

The Constant Function Rule. If f(x) = k, where k is a constant, then f′(x) = 0. In Leibniz notation, d/dx(k) = 0.
Proof: f′(x) = limh→0 [f(x + h) − f(x)]/h = limh→0 (k − k)/h = limh→0 0 = 0.

Example 1 — a. If f(x) = 5, f′(x) = 0.   b. If y = π/2, dy/dx = 0.

Solution. Both are constant functions, so their derivatives are zero by the constant function rule.

A power function has the form f(x) = xⁿ, where n is a real number. We observed f(x) = x² → f′(x) = 2x; g(x) = √x = x^(1/2) → g′(x) = (1/2)x^(−1/2) = 1/(2√x); h(x) = 1/x = x⁻¹ → h′(x) = −x⁻². We hypothesized d/dx(xⁿ) = nxⁿ⁻¹ — this is the power rule.

The Power Rule. If f(x) = xⁿ, where n is a real number, then f′(x) = nxⁿ⁻¹. In Leibniz notation, d/dx(xⁿ) = nxⁿ⁻¹.
Proof (n a positive integer): from the definition, f′(x) = limh→0 [(x + h)ⁿ − xⁿ]/h. Factoring gives [(x + h) − x][(x + h)ⁿ⁻¹ + (x + h)ⁿ⁻²x + … + xⁿ⁻¹]/h; dividing out h leaves n terms, each approaching xⁿ⁻¹, so the limit is nxⁿ⁻¹.

Example 2 — Differentiate:
a. f(x) = x⁷   b. g(x) = 1/x³   c. s = t^(3/2)   d. d/dx(x)

Solution.
a. f′(x) = 7x⁶.
b. g(x) = x⁻³, so g′(x) = −3x⁻⁴ = −3/x⁴.
c. ds/dt = (3/2)t^(1/2) = (3/2)√t.
d. d/dx(x) = 1x⁰ = 1.

The Constant Multiple Rule. If f(x) = kg(x), where k is a constant, then f′(x) = kg′(x). In Leibniz notation, d/dx(ky) = k·dy/dx.
Proof: f′(x) = limh→0 [kg(x + h) − kg(x)]/h = limh→0 k·[g(x + h) − g(x)]/h = k·limh→0 [g(x + h) − g(x)]/h = kg′(x).

Example 3 — Differentiate:
a. f(x) = 7x³   b. y = 12x^(4/3)

Solution.
a. f′(x) = 7·d/dx(x³) = 7(3x²) = 21x².
b. dy/dx = 12·d/dx(x^(4/3)) = 12·(4/3)x^(1/3) = 16x^(1/3).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercise 2.2.

Question 1 — Find f′(x): (a) f(x) = 4x − 7; (b) f(x) = ∛x; (c) f(x) = x⁻³.

(a) 4. (b) Rewrite as x^(1/3): f′(x) = (1/3)x^(−2/3). (c) f′(x) = −3x⁻⁴.

Question 2 — Differentiate 4x^(−1/2) − 6/x.

Rewrite 6/x as 6x⁻¹: derivative = 4(−1/2)x^(−3/2) − 6(−1)x⁻² = −2x^(−3/2) + 6x⁻².

Question 3 — Differentiate (1 + √x)/x.

Rewrite as x⁻¹ + x^(−1/2): derivative = −x⁻² − (1/2)x^(−3/2).

Question 4 — Name the three rules from this lesson and give an example of each.

Constant: f(x) = 7 → f′ = 0. Power: x⁵ → 5x⁴. Constant multiple: 3x⁴ → 12x³.

📝 Lesson Summary

Key ideas

  • Constant rule: d/dx(k) = 0.
  • Power rule: d/dx(xⁿ) = nxⁿ⁻¹, for any real n.
  • Constant multiple rule: d/dx(ky) = k·dy/dx.

Need to know

  • To differentiate a simple rational function such as 4/x⁶, express it as a power first: 4x⁻⁶ → −24x⁻⁷.
  • For a radical such as ∛(x⁵), rewrite as x^(5/3), then use the power rule: (5/3)x^(2/3).

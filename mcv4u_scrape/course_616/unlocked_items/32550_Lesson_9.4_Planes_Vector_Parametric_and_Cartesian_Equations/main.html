LESSON 9.4

Vector, Parametric, and Cartesian Equations of a Plane

Nelson Calculus and Vectors 12 §§8.4–8.6 — two direction vectors pin down a plane; one normal vector gives its Cartesian equation.

🎯 Learning Goals

By the end of this lesson, you can:

  • Write the vector and parametric equations of a plane from a point and two noncollinear direction vectors.
  • Write the Cartesian equation Ax + By + Cz + D = 0 from a point and a normal vector (built via the cross product).
  • Convert between forms, find the angle between two planes, and sketch planes from their Cartesian equations.

💡 Minds On

A line is one-dimensional: one parameter t generates every point. A plane is two-dimensional, so it needs two parameters and two direction vectors. Given a point P0 (position vector r0) and two noncollinear direction vectors a and b, every point P of the plane satisfies P0P = sa + tb — the vector equation r = r0 + sa + tb, s, t ∈ R. If the two "direction vectors" were collinear, sa + tb would only ever trace a line — the equation would collapse to a line, not a plane. There is no symmetric form for a plane.

📖 Learn — step by step

Vector and parametric equations of a plane

With r0 = (x0, y0, z0), a = (a1, a2, a3), b = (b1, b2, b3):

r = r0 + sa + tb,  s, t ∈ R
x = x0 + sa1 + tb1,  y = y0 + sa2 + tb2,  z =z0 + sa3 + tb3

The Cartesian equation of a plane

A normal n = (A, B, C) to the plane can be built as n = a × b from any two noncollinear direction vectors. For P(x, y, z) and P0(x0, y0, z0) on the plane, P0P is perpendicular to n, so n · P0P = 0 expands to:

Ax + By + Cz + D = 0, with D = −Ax0 − By0 − Cz0

Two planes with normals n1, n2 are parallel if n1 = kn2 (k ≠ 0) and perpendicular if n1 · n2 = 0. The angle between planes is the angle between their normals: θ = cos⁻¹((n1 · n2)/(|n1||n2|)), reported as the acute angle.

Sketching planes in R3

From Ax + By + Cz + D = 0: Case 1 (one variable, e.g. x = 5): a plane parallel to a coordinate plane. Case 2 (two variables, e.g. 2x − 5y = 10): if D = 0 the plane contains the missing-variable axis; otherwise find two intercepts and draw parallel to the missing axis. Case 3 (three variables, e.g. 2x + 3y − z = 4): if D = 0 use the origin plus two points; otherwise find the three intercepts and join them into a triangle.

Example 1 — Write vector and parametric equations of the plane through A(−1, 3, 8), B(−1, 1, 0), and C(4, 1, 1). Is P(14, 1, 3) on the plane? Is Q(14, 1, 5)?

Solution. (Direction vectors.) AB = (0, −2, −8) = −2(0, 1, 4), so use a = (0, 1, 4). AC = (5, −2, −7)… instead use BC = (5, 0, 1) = b. (Check: a and b are not collinear ✓.)
(Vector equation, anchored at A.) r = (−1, 3, 8) + s(0, 1, 4) + t(5, 0, 1),  s, t ∈ R.
(Parametric.) x = −1 + 5t,  y = 3 + s,  z = 8 + 4s + t.
(Test P(14, 1, 3).) From y: 3 + s = 1 → s = −2. From x: −1 + 5t = 14 → t = 3. Check z: 8 + 4(−2) + 3 = 3 ✓. P is on the plane (s = −2, t = 3).
(Test Q(14, 1, 5).) Same s = −2, t = 3 gives z = 3 ≠ 5. Q is not on the plane.
Answer: r = (−1, 3, 8) + s(0, 1, 4) + t(5, 0, 1); x = −1 + 5t, y = 3 + s, z = 8 + 4s + t. P is on the plane; Q is not.

Example 2 — Find the Cartesian equation of the plane through A(1, 2, 2) with normal n = (−1, 2, 6).

Solution. (Dot product method.) For P(x, y, z) on the plane, AP = (x − 1, y − 2, z − 2) and n · AP = 0:
(−1, 2, 6) · (x − 1, y − 2, z − 2) = 0 → −(x − 1) + 2(y − 2) + 6(z − 2) = 0 → −x + 2y + 6z − 15 = 0.
(Convention.) Multiply by −1 so the x-coefficient is positive and the integers stay simple:
Answer: x − 2y − 6z + 15 = 0.

Example 3 — Find the Cartesian equation of the plane through A(−1, 2, 5), B(3, 2, 4), and C(−2, −3, 6).

Solution. (Direction vectors.) AB = (4, 0, −1); AC = (−1, −5, 1).
(Normal via cross product.) n = AB × AC = |i j k; 4 0 −1; −1 −5 1| = i(0·1 − (−1)(−5)) − j(4·1 − (−1)(−1)) + k(4(−5) − 0(−1)) = (−5, −3, −20). Use the parallel normal (5, 3, 20).
(Cartesian equation through A.) 5x + 3y + 20z + D = 0 with 5(−1) + 3(2) + 20(5) + D = 0 → −5 + 6 + 100 + D = 0 → D = −101.
Answer: 5x + 3y + 20z − 101 = 0.

Example 4 — Find the acute angle between π1: x − y − 2z + 3 = 0 and π2: 2x + y − z + 2 = 0. Then sketch the plane 2x + 3y − z = 4.

Solution. (Angle from normals.) n1 = (1, −1, −2), n2 = (2, 1, −1).
cos θ = (n1 · n2)/(|n1||n2|) = (2 − 1 + 2)/(√6 · √6) = 3/6 = 1/2 = 0.5 → θ = 60° (acute).
(Sketch: three intercepts.) x-intercept: 2x = 4 → (2, 0, 0). y-intercept: 3y = 4 → (0, 4/3, 0). z-intercept: −z = 4 → (0, 0, −4). Join the three points into a triangle — that triangle represents the plane.

Answer: 60°. The plane 2x + 3y − z = 4 has intercepts (2, 0, 0), (0, 4/3, 0), (0, 0, −4).

✅ Check Your Understanding

Try these on paper first, then reveal. Modelled on Exercises 8.4–8.6.

Question 1 — Explain why r = (−1, 0, 1) + s(2, 3, −4) + t(4, 6, −8) is NOT the equation of a plane. What does it represent?

The two "direction vectors" (2, 3, −4) and (4, 6, −8) = 2(2, 3, −4) are collinear. So sa + tb = (s + 2t)(2, 3, −4) always points along a single direction — the equation describes a line through (−1, 0, 1) with direction (2, 3, −4), not a plane.

Question 2 — Write the Cartesian equation of the plane through P(−1, 2, 1), Q(3, 1, 4), and R(−2, 3, 5).

PQ = (4, −1, 3), PR = (−1, 1, 4). n = PQ × PR = |i j k; 4 −1 3; −1 1 4| = (−4 − 3, −(16 + 3), 4 − 1) = (−7, −19, 3), or (7, 19, −3). Through P: 7x + 19y − 3z + D = 0 → 7(−1) + 19(2) − 3(1) + D = 0 → −7 + 38 − 3 + D = 0 → D = −28. Answer: 7x + 19y − 3z − 28 = 0.

Question 3 — For the planes π1: 4x + ky − 2z + 1 = 0 and π2: 2x + 4y − z + 4 = 0: (a) find k so they are parallel; (b) find k so they are perpendicular.

(a) Parallel ⇔ normals are multiples: (4, k, −2) = m(2, 4, −1). From the x-components m = 2, so k = 2·4 = 8. (The constants 1 and 4 are not in ratio 2, so the planes are parallel and distinct.)
(b) Perpendicular ⇔ (4, k, −2) · (2, 4, −1) = 0 → 8 + 4k + 2 = 0 → k = −5/2.

Question 4 — Sketch the plane 2x − 5y = 10. Which axis is it parallel to, and why?

Intercepts: x-intercept (5, 0, 0); y-intercept (0, −2, 0). Setting x = y = 0 gives 0 = 10 — impossible, so there is no z-intercept. The plane is parallel to the z-axis because the equation contains no z term: changing z never affects whether a point satisfies the equation.

📝 Lesson Summary

Key ideas

  • Vector/parametric plane: r = r0 + sa + tb (two parameters, two noncollinear direction vectors).
  • Cartesian plane: Ax + By + Cz + D = 0, with normal n = (A, B, C) = a × b.
  • Angle between planes: angle between normals (acute). Parallel ⇔ normals are multiples; perpendicular ⇔ normals' dot product is 0.
  • Sketching: 1 variable → parallel to a coordinate plane; 2 variables → parallel to the missing axis; 3 variables → intercept triangle.

Need to know

  • Cartesian → vector: set two variables as parameters (s, t) and solve for the third; or use three points.

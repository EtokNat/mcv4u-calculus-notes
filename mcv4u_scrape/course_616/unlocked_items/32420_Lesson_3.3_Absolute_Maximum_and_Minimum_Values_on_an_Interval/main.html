  • Decide when the algorithm does not apply.

💡 Minds On

Where does a function attain its largest and smallest values on an interval? Completing the square on quadratics suggests maxima/minima occur where f′(c) = 0 — but trying more intervals shows extrema can also occur at the interval's endpoints. Conclusion: on an interval, the maximum occurs at a "peak" (f′(c) = 0) or an endpoint; the minimum at a "valley" (f′(c) = 0) or an endpoint — no matter how many peaks and valleys the graph has.

📖 Learn — step by step

Algorithm for Finding Maximum or Minimum (Extreme) Values. If f(x) has a derivative at every point in a ≤ x ≤ b, calculate f(x) at:
  • all points in a ≤ x ≤ b where f′(x) = 0,
  • the endpoints x = a and x = b.
The maximum value of f(x) on a ≤ x ≤ b is the largest of these values; the minimum is the smallest. Use a finite (closed) interval — otherwise the function may not attain a maximum or minimum.

Example 1 — Find the extreme values of f(x) = −2x³ + 9x² + 4 on the interval x ∈ [−1, 5].

Solution. The derivative is f′(x) = −6x² + 18x. Setting f′(x) = 0 gives −6x(x − 3) = 0, so x = 0 or x = 3 — both lie in [−1, 5]. Evaluate f at these values and at the endpoints x = −1 and x = 5:
f(−1) = 15;   f(0) = 4;   f(3) = 31;   f(5) = −21.
Therefore, the maximum value of f(x) on −1 ≤ x ≤ 5 is f(3) = 31, and the minimum value is f(5) = −21. Graphing the function on this interval verifies the analysis.

Example 2 — The current, in amperes, in an electrical system is C(t) = −t³ + t² + 21t, where t is the time in seconds and 0 ≤ t ≤ 5. Determine the times at which the current is at its maximum and minimum, and the current at these times.

Solution. The derivative is dC/dt = −3t² + 2t + 21. Setting dC/dt = 0:
−3t² + 2t + 21 = 0   (Multiply by −1)
3t² − 2t − 21 = 0   (Factor)
(3t + 7)(t − 3) = 0   (Solve)
t = −7/3 or t = 3.
Only t = 3 is in the interval, so evaluate C at t = 0, 3, and 5:
C(0) = 0;   C(3) = −3³ + 3² + 21(3) = 45;   C(5) = −5³ + 5² + 21(5) = 5.
The maximum is 45 A at t = 3 s, and the minimum is 0 A at t = 0 s.

Example 3 — The light intensity on a point is I(t) = (t² + 2t + 16)/(t + 2), where t is the time in seconds and t ∈ [0, 14]. Determine the time of minimal intensity.

Solution. The function is not defined at t = −2, but that value is not in the interval. The derivative is
I′(t) = [(2t + 2)(t + 2) − (t² + 2t + 16)(1)]/(t + 2)²   (Quotient rule)
= [2t² + 6t + 4 − t² − 2t − 16]/(t + 2)²   (Expand and simplify)
= (t² + 4t − 12)/(t + 2)².
Setting I′(t) = 0 means the numerator is 0: t² + 4t − 12 = 0 → (t + 6)(t − 2) = 0, so t = −6 or t = 2. Only t = 2 is in the interval. Evaluate:
I(0) = 8;   I(2) = (4 + 4 + 16)/4 = 6;   I(14) = (196 + 28 + 16)/16 = 15.
Shortcut: rewriting I(t) = t + 16/(t + 2) gives I′(t) = 1 − 16/(t + 2)², and setting it to 0 gives the same t = 2.
Either way, the minimum light intensity occurs at t = 2 s.

For each graph, the absolute maximum is the highest point shown on the interval and the absolute minimum the lowest — check whether each occurs at a peak/valley or at an endpoint.

Question 2 — Find the absolute extrema of f(x) = x² − 4x + 3 on [0, 3].

f′(x) = 2x − 4 = 0 → x = 2. f(0) = 3, f(2) = −1, f(3) = 0. Maximum 3 at x = 0; minimum −1 at x = 2.

Question 3 — Which points on an interval must be considered to find absolute max/min, and why?

Points where f′(x) = 0 (peaks/valleys) and the endpoints — because extrema can occur at either, as the investigation showed.

Question 4 — Does the algorithm apply to y = 3x/(x − 2) on [−1, 3]? Give a reason.

No — the function is not defined at x = 2 (inside the interval), so it does not have a derivative at every point of [−1, 3].

📝 Lesson Summary

Key ideas

  • Absolute extrema on an interval occur at peaks/valleys (f′(c) = 0) or at endpoints.
  • Algorithm: evaluate f at all points with f′(x) = 0 and at both endpoints; largest = maximum, smallest = minimum.

Need to know

  • The interval must be finite (closed); the function must be differentiable at every point of it.

## choice (3.0 pts)

**Prompt:**

```
A student writes the "symmetric equations" of the line r = (0, 1, -3) + t(2, 5, 0) as x/2 = (y - 1)/5 = (z + 3)/0. What is the error?
```

**Choices:**
- The z direction number is 0, so z = -3 must be written separately: x/2 = (y - 1)/5, z = -3.
- The anchor point should be (2, 5, 0).
- The direction vector should be (0, 1, -3).
- There is no error - this is correct.

## multi-answer (2.0 pts)

**Prompt:**

```
A student computes the distance from P(4, 1, -2) to the plane 3x - 2y + z = 8. Which of the following steps are correct?
```

**Choices:**
- The denominator is sqrt(9 + 4 + 1) = sqrt(14)
- The distance is 0
- The numerator is |3(4) - 2(1) + (-2) - 8| = 0
- The distance is 8/sqrt(14)

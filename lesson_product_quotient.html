The Product and
Quotient Rules

MCV4U · Calculus and Vectors

Lesson 1 · the first new differentiation rules

What you should already know

  • Power rule: \(\dfrac{d}{dx}x^{n} = nx^{n-1}\)
  • Sum/difference rule: \((f\pm g)' = f'\pm g'\)
  • The basic trig derivatives: \(\dfrac{d}{dx}\sin x = \cos x\), \(\dfrac{d}{dx}\cos x = -\sin x\)

Why we need a new rule

Does the derivative distribute over multiplication? Let's test.

Let \(f(x) = x\) and \(g(x) = x\).

Then \(f(x)g(x) = x^{2}\), so \((fg)'(x) = 2x\).

But \(f'(x)\,g'(x) = 1\cdot 1 = 1\).

\((fg)' \ne f'\,g'\). The derivative does not distribute — we need a proper rule.

Part 1 — The Product Rule

The Product Rule

If \(f\) and \(g\) are differentiable, then

\[\dfrac{d}{dx}\bigl[f(x)\,g(x)\bigr] = f'(x)\,g(x) + f(x)\,g'(x).\]

Memory phrase: "first-prime second, plus first second-prime."

Example 1 — \(f(x) = (3x+2)(2x^{2}-1)\)

Step 1. Let \(u = 3x+2\), \(v = 2x^{2}-1\).

Step 2. \(u' = 3\), \(v' = 4x\).

Step 3. Product rule: \(f'(x) = u'v + uv'\).

Step 4. \(f'(x) = 3(2x^{2}-1) + (3x+2)(4x)\).

Step 5. Expand: \(= 6x^{2}-3 + 12x^{2}+8x\).

\(f'(x) = 18x^{2} + 8x - 3.\)

Example 2 — \(f(x) = x\sin x\)

Step 1. \(u = x\), \(v = \sin x\).

Step 2. \(u' = 1\), \(v' = \cos x\).

Step 3. \(f'(x) = (1)(\sin x) + (x)(\cos x)\).

\(f'(x) = \sin x + x\cos x.\)

Example 3 — bigger polynomials

\(f(x) = (3x^{2} - 5x + 1)(2x^{3} - 7x^{2} + 2x - 5)\).

Step 1. \(u' = 6x-5\), \(v' = 6x^{2}-14x+2\).

Step 2. Apply product rule:

\(f'(x) = (6x-5)(2x^{3}-7x^{2}+2x-5) + (3x^{2}-5x+1)(6x^{2}-14x+2).\)

Leave it factored — you do not need to multiply out.

For three factors

\[(uvw)' = u'vw + uv'w + uvw'.\]

Each factor takes a turn getting differentiated while the others sit still.

The pattern generalises: for \(n\) factors there are \(n\) terms.

Example 4 — tangent to a product at a point

Find the tangent to \(y = (x^{2}+1)(2x-3)\) at \(x = 1\).

Step 1 — the point. \(y(1) = (2)(-1) = -2\), so point \(= (1,\,-2)\).

Step 2 — the slope. \(y'(x) = (2x)(2x-3) + (x^{2}+1)(2)\).

Step 3. Simplify: \(y'(x) = 6x^{2} - 6x + 2\).

Step 4. At \(x=1\): \(y'(1) = 6-6+2 = 2\).

Step 5. Tangent equation: \(y - (-2) = 2(x - 1)\).

\(y = 2x - 4.\)

Part 2 — The Quotient Rule

The Quotient Rule

If \(f\) and \(g\) are differentiable and \(g(x) \ne 0\), then

\[\left(\dfrac{f}{g}\right)' = \dfrac{f'(x)\,g(x) - f(x)\,g'(x)}{\bigl[g(x)\bigr]^{2}}.\]

Memory phrase: "low d-high minus high d-low, over the square of what's below."

Order matters. The numerator is \(f'g\) minus \(fg'\) — swap them and the sign flips.

Example 5 — \(y = \dfrac{\sin x}{\cos x}\)

Step 1. \(f = \sin x\), \(g = \cos x\).

Step 2. \(f' = \cos x\), \(g' = -\sin x\).

Step 3. \(y' = \dfrac{(\cos x)(\cos x) - (\sin x)(-\sin x)}{\cos^{2} x}\).

Step 4. Numerator: \(\cos^{2}x + \sin^{2}x = 1\).

Step 5. So \(y' = \dfrac{1}{\cos^{2} x} = \sec^{2} x\).

\(\dfrac{d}{dx}\tan x = \sec^{2} x.\)

Example 6 — \(y = \dfrac{x^{2}+1}{x-1}\) two ways

Route A — quotient rule.

\(y' = \dfrac{(2x)(x-1) - (x^{2}+1)(1)}{(x-1)^{2}}\)

\(= \dfrac{2x^{2}-2x-x^{2}-1}{(x-1)^{2}} = \dfrac{x^{2}-2x-1}{(x-1)^{2}}.\)

Route B — product rule on \((x^{2}+1)(x-1)^{-1}\).

\(y' = (2x)(x-1)^{-1} + (x^{2}+1)\cdot(-1)(x-1)^{-2}\)

\(= \dfrac{2x(x-1) - (x^{2}+1)}{(x-1)^{2}} = \dfrac{x^{2}-2x-1}{(x-1)^{2}}.\)

Same answer either route. Route B is what the Ontario curriculum formally requires.
